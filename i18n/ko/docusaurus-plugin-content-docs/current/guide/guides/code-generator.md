# 코드 생성

툴바의 `Code Generator` 탭으로 전환한 뒤, 코드 영역에서 마우스 오른쪽 클릭으로 컨텍스트 메뉴를 엽니다.  
다음의 목록을 지원합니다.

- GraphQL
- C#
- Java
- Kotlin
- TypeScript
- JPA
- Scala

같은 컨텍스트 메뉴에서 `Table Name Case`와 `Column Name Case`도 제공하며, 각각 `Pascal`, `Camel`, `Snake`, `None`을 지원합니다.
