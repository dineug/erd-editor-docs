# Undo, Redo

편집 이전 상태와 이후 상태로 되돌아갈 수 있습니다.  
히스토리 최대 크기는 `2048`개 변경사항을 기록합니다.

- Undo: `Ctrl + Z` (Windows/Linux) or `⌘ + Z` (Mac)
- Redo: `Ctrl + Shift + Z` (Windows/Linux) or `⌘ + Shift + Z` (Mac)

Undo, Redo는 ERD 탭에서만 동작합니다. Visualization, Schema SQL, Code Generator, 설정 탭에서는 사용할 수 없습니다.

## Time Travel

툴바의 Undo, Redo 옆에서 열 수 있습니다.
슬라이더를 움직여 편집 히스토리 전체를 확인한 뒤, `Apply`로 선택한 시점을 적용하거나 `Cancel`로 문서를 그대로 둡니다.
