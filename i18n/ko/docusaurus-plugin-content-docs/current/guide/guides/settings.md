# 설정

툴바의 Settings 버튼으로 열 수 있습니다.
설정 화면은 `Preferences`와 `Shortcuts` 두 개의 탭으로 구성됩니다.
`Shortcuts` 탭에서 모든 명령의 현재 단축키를 확인할 수 있습니다.

## 관계 데이터 타입 동기화

데이터 타입 동기화여부를 결정합니다.

<img src="/img/settings-relationship-data-type-sync.png" width="400" alt="관계 데이터 타입 동기화 설정" loading="lazy" />

![demo-relationship-data-type-sync](/img/demo-relationship-data-type-sync.webp)

## 스크롤 정보 저장

스크롤 위치를 문서에 저장할지 결정합니다.

## 확대/축소 정보 저장

확대/축소 레벨을 문서에 저장할지 결정합니다.

## 코멘트 최대 너비

코멘트 컬럼의 최대 너비를 픽셀 단위로 지정합니다 (`60` ~ `200`).
스위치를 끄면 제한이 없어집니다.

## 컬럼 순서 조정

테이블에 표출되는 컬럼 순서를 설정합니다.

## 테이블 너비 재계산

`Sync`를 누르면 모든 테이블의 너비를 현재 내용에 맞게 다시 계산합니다.
