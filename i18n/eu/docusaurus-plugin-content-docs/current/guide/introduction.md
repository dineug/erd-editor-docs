# Sarrera

erd-editor entitate-erlazio diagramen editore bat da.
Web aplikazio, Google Drive aplikazio, VS Code luzapen, IntelliJ plugin, Obsidian plugin eta zure orrian txerta dezakezun `<erd-editor>` elementu pertsonalizatu gisa dago eskuragarri, eta haren ondoan `<erd-viewer>` diagrama bat irakurtzeko soilik erakusteko.
Bere scriptik kargatzen ez duen gune batek, horren ordez, irakurtzeko soilik dagoen diagrama bat txerta dezake erd-editor.io/embed helbidetik.
Guztietan editore bera eta dokumentu-formatu bera erabiltzen dira.

![Denda baten diagrama: erlazio baten gainetik pasatzea, zutabe bat gehitzea eta orders taula Fluxu moduan fokuratzea](/img/demo-overview.webp)

IDE batean probatzeko, sortu `.erd.json` luzapena duen fitxategi huts bat eta ireki.
Obsidianen, exekutatu `ERD Editor: Create new diagram` komandoa komando-paletatik, edo aukeratu `New ERD` fitxategi-arakatzaileko karpeta baten laster-menuan. Bietako edozeinek `.erd` fitxategi huts bat sortzen eta irekitzen du.
Google Drive zerbitzuan, aukeratu New → More → ERD Editor, eta ondoren hasi saioa Google kontuarekin. ERD Editor aplikazioak harekin sortzen edo irekitzen dituzun fitxategiak soilik atzitzen ditu.
Web aplikazioan, Google Drive zerbitzuan, VS Code editorean, JetBrains IDE batean eta Obsidianen, diagrama berri eta huts bat [ongietorri-pantailan](./guides/editing-start.md#welcome-screen) irekitzen da, lehen urratsak eskaintzen dituen menu batean: `New Table`, `New Memo`, `Import`, `Command Palette` eta `Shortcuts`.
Korritzeak, zooma aldatzeak, fitxaz aldatzeak eta Izenen ikuspegia aldatzeak diagrama berri baten fitxategi hutsa dagoen bezala uzten dute, diagrama berri batean blokeo guztiak aktibatuta baitaude. Ikus [Blokeoa](./guides/settings.md#lock).
VS Code editoreak ERD fitxategi bat JSON testu gisa irekitzen du Source Control, Local History eta Compare with Saved ikuspegietan, VS Coderen txataren eta GitHub Copilot eta Claude Code bezalako kodetze-agenteen edizio-berrikusketetan, eta GitLens, GitHub Pull Requests eta Git Graph bezalako luzapenen berrikuspen-ikuspegietan; beraz, aldaketa bat lerroz lerro alderatzen da. `Reopen Editor With...` komandoak Git berrikuspen bat irakurtzeko soilik dagoen diagrama gisa erakusten du.

Obsidian plugina eguneratu ondoren, berrabiarazi Obsidian: ordura arte, leihoak aurreko bertsioak kargatutako editorea mantentzen du.
Eguneratu ERD Editor eta `@dineug/erd-editor-mcp` diagramak partekatzen dituzun leku guztietan. Hiztegia fitxa baino lehenagoko bertsio batek, edo diskoko fitxategi bat editatzen duen MCP zerbitzari zaharrago batek, diagrama haren izen logikorik, domeinu-loturarik eta hiztegirik gabe gordetzen du. Taula-taldeak sartu aurreko bertsio batek, gainera, ez du gako nagusien ikonorik erakusten uneko bertsioak gordetako fitxategi batean, eta fitxategia han gordetzeak haren taula-taldeak eta SQL eskemako scriptak kentzen ditu.
Bertsio zaharrago batek gordetako fitxategi bat uneko forman berridazten da fitxategian gordetzen den lehen aldaketan. Ikus [Blokeoa](./guides/settings.md#lock). Gordetze horrek bertsio zaharragoak idatzitako testu hutsak, zerrendak eta bildumak ere kentzen ditu; beraz, edizioak baino gehiago aldatzen du fitxategitik. Ordura arte, taula-taldeak baino lehenagoko bertsio bateko fitxategi bat bere `$schema` propietatearen arabera balidatzen duen JSON editore batek baliogabetzat jotzen du.

## Zer egiten duen {#what-it-does}

- Marraztu taulak, zutabeak eta oharrak oihal mugagabe batean, eta lotu haiek lau erlazio motarekin: `Zero One`, `Zero N`, `One Only`, `One N`. Ikus [Editatzen hastea](./guides/editing-start.md). Indizeak taularen propietate-panelean definitzen dira. Bi zutabe edo gehiagoko indize bakarra gako alternatiboa da, eta `Alternate Key` ikuspegi-aukera aktibatuta dagoenean, diagramak haren zutabeei `AK1.1`, `AK1.2` eta abar ezartzen dizkie. Ikus [Indizeak](./guides/table-related-functions.md#indexes) eta [Gako alternatiboak](./guides/table-related-functions.md#alternate-keys).
- Amaitu erlazio bat taula batek dagoeneko dituen zutabeetan: erlazioa sagu edo arkatz batekin marrazten duzun bitartean, erlazioa amaitzen den taularen ondoko `Map to existing columns` aukerak taula gurasoaren gakoa taula horren zutabeekin parekatzen du, eta `Create new columns` aukerak zutabe berriak gehitzen ditu. Erlazio baten laster-menuko `Map Columns` aukerak haren zutabeak geroago aldatzen ditu. Ikus [Mapatu zutabeak](./guides/relationship-editing.md#map-columns). Erlazio batek ON DELETE eta ON UPDATE ekintzak ere izan ditzake. Ikus [ON DELETE eta ON UPDATE](./guides/relationship-editing.md#on-delete-and-on-update).
- Editatu azkar: `Alt + N` lasterbideak taula bat gehitzen du; `Alt + Enter` lasterbideak zutabe bat gehitzen du; `Alt + K` lasterbideak gako nagusia aktibatzen edo desaktibatzen du fokuratutako zutabean, edo hautatutako zutabe guztietan, fokuratutakoa horietako bat denean; eta `Delete` edo `Backspace` teklak hautapena ezabatzen du. Bakoitza desegite-urrats bat da. Ikus [Lasterbideak](./guides/settings.md#shortcuts). Oihalaren behealdean dagoen [oihaleko tresna-barrak](./guides/table-related-functions.md#canvas-toolbar) ere klik bakarrez gehitzen du taula edo ohar bat.
- Koloreztatu taula, ohar edo taula-talde bat kolore aurrezarriak eta diagramak dagoeneko erabiltzen dituen koloreak dituen hautatzaile batetik, eta kendu kolorea `No color` edo `Remove color` aukerarekin. Ikus [Taulen eta oharren kolorea ezartzea](./guides/table-related-functions.md#table-and-memo-color-specification).
- Bildu erlazionatutako taulak [taula-taldeetan](./guides/table-groups.md): haien atzean dagoen koadro bat, izena eman eta koloreztatu dezakezuna. Marraztu talde bat `Alt + G` lasterbidearekin edo oihalaren laster-menuko, oihaleko tresna-barrako edo Bilaketa azkarreko `New Table Group` aukerarekin, edo sortu talde bat hautatutako tauletatik `T` eta ondoren `G` sakatuta edo haien laster-menuko `Group selected tables` aukerarekin. Taula bat talde batean sartzen da barruan askatzen duzunean, eta irten egiten da kanpoan askatzen duzunean, eta talde bat titulu-barratik arrastatzean haren taulak harekin batera mugitzen dira. DBML formatuak taldeak bi noranzkoetan eramaten ditu, `TableGroup` bloke gisa.
- Eman taulei eta zutabeei [izen logikoak](./guides/logical-names.md), jendeak irakurtzen dituen izenak, adibidez `Customer Name` `CUST_NM` izenarentzat, SQL eskemak eta Kode-sortzaileak idazten dituzten izen fisikoen ondoan. Izenen ikuspegiak (`Physical Names`, `Logical Names` edo `Both Names`) erabakitzen du oihalak horietako zein marrazten duen, eta taula edo zutabe bat izendatzen duten [beste leku gehienek](./guides/logical-names.md#beyond-the-canvas), adibidez Arakatzaileko taula- eta zutabe-errenkadek, Fluxuak eta esportatutako irudi batek, hari jarraitzen diote. Aukeratu oihaleko tresna-barrako `Name View` botoitik, oihalaren laster-menutik, Bisualizazioaren tresna-barratik `Flow` moduan, edo Bilaketa azkarretik.
- Gorde diagramaren izendapen-estandarra [Hiztegia](./guides/dictionary.md) fitxan. Haren `Domains`, `Words` eta `Terms` orriak kalkulu-orri bat bezala bilatu, ordenatu eta editatzen dira, eta bakoitzak bere desegite-historia du. Orriek CSV fitxategiak inportatzen eta esportatzen dituzte: inportazio batek editorearen beraren fitxategi-egitura edo Koreako datu publikoen estandarrarena irakurtzen du, UTF-8 edo EUC-KR kodeketan, eta esportazio batek editorearena idazten du. Izen logikoaren gelaxkak termino-izenak osatzen ditu. Izen logiko batek izen fisiko bat ematen dio bere taulari edo zutabeari, bat datorren terminotik edo zatitzen den hitzen laburduretatik, zuk zeuk izena idatzi arte. Hitz edo termino bat aldatu ondoren, [`Derive Physical Names Again`](./guides/dictionary.md#derive-physical-names-again) aukerak izenak berriro eratortzen ditu, zuk idatzitako izenak barne. Domeinu bati lotutako zutabe batek, eskuz edo bere terminoaren bidez lotuta, [domeinuaren datu mota hartzen du](./guides/dictionary.md#domains-and-data-types) eta haren aldaketei jarraitzen die, eta `Domain` ikuspegi-aukerak zutabe bakoitzaren domeinua erakusten du. [`Checks`](./guides/dictionary.md#the-checks-sheet) orriak hitz debekatuak, erregistratu gabeko hitzak eta sinonimoak, izen bikoiztuak, domeinu ezezagunak, beren terminoarenaz bestelako izen fisikoak eta beren domeinuarenaz bestelako zutabe-motak zerrendatzen ditu. Oihalak hitzen eta terminoen egiaztapenek seinalatzen dituzten izen logikoak eta fisikoak koloreztatzen ditu.
- Inportatu lehendik dagoen eskema bat `json`, `Schema SQL`, `GraphQL`, `DBML` edo `AML` formatutik. Ikus [Fitxategiak inportatzea edo esportatzea](./guides/file-import-export.md). SQL eskema, GraphQL, DBML edo AML fitxategi bat inportatzean, haren taulak erlazioei jarraituz antolatzen dira, edo errenkadatan erlaziorik ez badu. [`Import and Add`](./guides/file-import-export.md#import-and-add) aukerak fitxategi bat diagramaren azpian gehitzen du, hura ordeztu beharrean.
- Esportatu diagrama `json` formatuan; SQL eskema gisa [SQL eskema](./guides/schema-sql.md#saving-or-copying-the-sql) fitxatik, `.sql` fitxategi gisa gordeta edo kopiatuta; edo [`Export image`](./guides/file-import-export.md#image) elkarrizketa-koadrotik PNG edo SVG irudi gisa, edo PNG gisa arbelean.
- Erakutsi diagrama bat irakurtzeko soilik beste gune batean: txertatu iframe batean [erd-editor.io/embed](./guides/embedding.md) fitxategi baten URLarekin, GitHub-ekoa barne, edo kargatu [`<erd-viewer>`](../api/erd-viewer-element.md) elementua zure orrian. Irakurle batek diagrama mugitu, zoomarekin handitu, bilatu eta erlazioak pizten ditu, eta ezerk ez du diagrama editatzen.
- Idatzi SQL eskema zortzi datu-base hornitzaileren sintaxian: Databricks, MSSQL, MariaDB, MySQL, Oracle, PostgreSQL, Snowflake eta SQLite. Ikus [Taulekin lotutako funtzioak](./guides/table-related-functions.md#databases). [SQL eskema](./guides/schema-sql.md) fitxako aukeren panelak idatzi beharreko sententziak, goiburua eta taula-taldeak aukeratzen ditu, [izen logikoak iruzkin hutsetan idatz ditzake](./guides/schema-sql.md#logical-names-as-comments), eta zure SQL propioa diagraman gordetzen du, taulen aurretik eta ondoren idazteko.
- Sortu kodea hogeita bi helburutarako: C#, Go, Java, Kotlin, PHP, Rust, Scala, Swift eta TypeScript lengoaiak; Doctrine, Drizzle, JPA, SeaORM, Sequelize, SQLAlchemy eta TypeORM ORMak; eta AML, DBML, GraphQL, JSON Schema, Mermaid eta Zod. Kode-sortzailea fitxako aukeren panelak lengoaia, datu-basea eta izenen idazkerak aukeratzen ditu, eta kodea lengoaiaren luzapena duen fitxategi gisa gordetzen da edo kopiatu egiten da. Ikus [Kode-sortzailea](./guides/code-generator.md).
- Irakurri eskema [Bisualizazioa](./guides/visualization.md) fitxan, indarretan oinarritutako `Graph` gisa edo erlazioei jarraituz antolatutako taula-txartelen `Flow` gisa; bertan, taula baten gainetik sagua pasatzean, taulak ukitzen duen guztia argiztatzen da. Sakatu `Alt + F` ERD fitxan [hautatutako taulak fokuratzeko](./guides/visualization.md#focusing-on-tables), haiekin erlazionatutako taulekin batera. `Flow` moduan, [`Previous table` eta `Next table`](./guides/visualization.md#previous-table-and-next-table) botoiek Fluxua murriztuz joan den urratsetan atzera eta aurrera egiten dute, desegiteko eta berregiteko teklek bertan egiten duten bezala.
- Lan egin ertzik gabeko oihal batean: mugitu ikuspegia diagrama hedatzen den edonora, egin zoom `10%` eta `150%` artean `Ctrl + Wheel` (Mac sisteman, `⌘ + Wheel`) lasterbidearekin, teklatuarekin edo atximurtze-keinu batekin, eta kendu bistatik dena, diagrama izan ezik, zen moduarekin. Saguaren erdiko botoiarekin arrastatzeak ikuspegia mugitzen du oihaleko edozein lekutatik, baita taula baten gainetik ere. Ikus [Oihalean zehar mugitzea](./guides/table-related-functions.md#getting-around-the-canvas).
- Antolatu diagrama oso bat urrats bakarrean [Antolaketa automatikoa](./guides/table-related-functions.md#auto-layout) erabiliz: indar-simulazio bat, ezkerretik eskuinerako fluxu bat edo bi norabideetako edozeinetan zuhaitz bat, taula-talde bakoitzaren taulak elkarrekin mantenduz.
- Exekutatu komando bat edonondik [Bilaketa azkarra](./guides/quick-search.md) erabiliz, edo hasi bilaketa `#`, `@` edo `:` ikurrarekin taula batera, zutabe batera, edo iruzkin edo ohar batera jauzi egiteko; `#` eta `@` aurrizkiak izen logikoekin ere bat datoz. Ibili edizio-historian urratsez urrats [Desegin eta berregin](./guides/undo-redo.md) erabiliz, erreproduzitu saio honen historia oihalean [Denbora-bidaia](./guides/undo-redo.md#time-travel) erabiliz, edo alderatu diagrama beste `.json` fitxategi batekin [Diferentzia-ikustailean](./guides/table-related-functions.md#diff-viewer). Haren zuhaitzak, bi bertsioen ondoan, gehitu, aldatu edo ezabatu diren edo izena aldatu zaien taulak, zutabeak, indizeak, gako arrotzak, oharrak eta taula-taldeak zerrendatzen ditu.
- Arakatu diagrama [Arakatzailean](./guides/explorer.md), oihalaren ezkerrean ainguratutako zuhaitz batean: taulak, bakoitza bere zutabe, indize eta gako arrotzekin, eta ondoren taula-taldeak eta oharrak. Egin klik errenkada batean oihalean adierazten duen elementura joateko; gako arrotz baten errenkadak dagokion erlazioa ere argiztatzen du. Tresna-barrako `Explorer` botoiak, `Search` botoiaren ondoan dagoenak, irekitzen eta ixten du.
- Bilatu testua Arakatzailearen goialdean dagoen [Bilatu eta ordeztu](./guides/find-and-replace.md) funtzioarekin. Taulen, zutabeen, indizeen eta taula-taldeen izenetan bilatzen du, baita taulen eta zutabeen izen logikoetan ere, eta, haiek aktibatzen dituzunean, iruzkinetan eta oharretan, eta bat-etortzeak Arakatzailearen zuhaitzean erakusten ditu. Ordeztu bat-etortze bat edo guztiak; `Preserve Case` aukerak ordezpen bakoitzari ordezten duen testuaren maiuskulak eta minuskulak ematen dizkio. `Ctrl + F` (Mac sisteman, `⌘ + F`) lasterbideak Arakatzailea irekitzen du testu-kurtsorea Bilatu eremuan dagoela, eta berriro sakatzeak Arakatzailea ixten du.
- Erabili editorea 25 hizkuntzatan, tresna-barrako `Display Language` botoitik edo Bilaketa azkarretik aukeratuta. `System` aukerak nabigatzailearen edo aplikazio ostalariaren hizkuntzari jarraitzen dio, eta arabierak, hebreerak eta persierak editorea eskuinetik ezkerrera antolatzen dute, diagrama ezkerretik eskuinera geratzen den bitartean. Editorearen testua bakarrik aldatzen da: izenak, SQLa eta sortutako kodea idatzita dauden bezala geratzen dira. Tresna-barrako gai-sortzaileak itxura (`System`, `Light` edo `Dark`), gris-tonu bat eta nabarmentze-kolore bat aukeratzen ditu. Ikus [Hizkuntza eta gaia](./guides/language-and-theme.md).
- Mantendu diferentziak garbi: korritze-posizioa eta zooma, irekita dagoen fitxa, Kode-sortzailearen lengoaia eta izenen idazkerak, mugatzaile mota eta Izenen ikuspegia lehenespenez [blokeatuta](./guides/settings.md#lock) daude; beraz, fitxategiak blokeatu zirenean zituzten balioak gordetzen ditu, eta korritzeak, zooma aldatzeak, fitxaz aldatzeak edo Izenen ikuspegia aldatzeak ez du inoiz hura aldatzen. Fitxategia ordena finko batean idazten da, lerro bat hiztegiko errenkada bakoitzeko, eta kanpoan uzten ditu neurtutako zabalerak, pilatze-ordena, konektoreen aingura-puntuak, kendutako elementuak, elementu baten testu hutsa, eta diagramak bat ere ez duen motako zerrendak eta bildumak; beraz, diagrama bat ireki eta editatu gabe ixteak fitxategia zegoen bezala uzten du.
- Utzi Claude Code edo Codex bezalako kodetze-agente bati diagrama editatzen [MCP zerbitzariaren](../mcp/introduction.md) bidez: zuzenean VS Code editorean, Obsidianen edo JetBrains IDE batean, aldaketa bakoitza gertatu ahala oihalean agertzen dela, edo fitxategian bertan. Izen logikoak eta zutabeen domeinuak ere ezar ditzake, [hiztegiak editatu](../mcp/tools.md#dictionaries), izen fisikoak berriro eratorri, eta `Checks` orriak aurkitzen duena zerrendatu.
- Editatu elkarrekin denbora errealean web aplikazioan (esperimentala). Saioak parekoen artekoak eta muturretik muturrera zifratuak dira; beraz, ez dago zure eskema gordetzen duen zerbitzaririk, eta parekoek elkarren kurtsoreak, fokua eta hautapenak ikusten dituzte. Zure orrian, [`getSharedStore()`](../api/advanced/collaborative-editing.md) funtzioak ekintza-jario bera ematen dizu nahi duzun garraioaren bidez.

## Proiektu honen arrazoia {#reason-behind-this-project}

Lehendik zeuden modelatze-tresnek ez zuten nik nahi nuen erabiltzaile-esperientziaren maila eskaintzen.  
Horregatik, proiektu hau hasi nuen erabiltzaile-esperientziarik onena eskaintzeko.  
Proiektuaren lehentasun nagusia erabiltzailearen edizio-esperientzia da.  
Editatzean esperientzia harrigarria eskainiko dizu.
