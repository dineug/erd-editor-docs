# 可視化

ドキュメント全体を、次の 2 つのモードのいずれかで一目で把握できるように表示します。

- `Graph`。すべてのテーブルとそのカラム、テーブル間のリレーションシップを表す力学モデルのグラフです。[Graph モード](#graph-mode)を参照してください。
- `Flow`。すべてのテーブルをカードとして描画し、リレーションシップに沿って並べます。[Flow モード](#flow-mode)を参照してください。

上部のツールバーの `Visualization` タブから開きます。[クイック検索](./quick-search.md)の `Tab` からも開けます。  
ERD タブで `Alt + F` (Windows/Linux) または `⌥ + F` (Mac) を押すか、テーブルのコンテキストメニューの `Focus on this table` を選ぶと、選んだテーブルと、そこからリレーションシップ 1 つでつながるテーブルに絞り込んだ状態で、直接 `Flow` で開きます。[テーブルへのフォーカス](#focusing-on-tables)を参照してください。

モードは[ツールバー](#toolbar)の左端にある `Graph` と `Flow` のボタンで切り替えます。  
新しく開いたエディタは `Graph` で始まります。選んだモードはエディタを開いている間、ほかのタブを行き来しても保たれますが、ドキュメントには保存されません。

## ツールバー {#toolbar}

タブの下端中央にツールバーが浮いています。左から順に次のものが並びます。

- `Graph` と `Flow`。現在のモードが強調表示されます。
- `Zoom out`、`100%` のようなパーセントで示した現在の倍率、`Zoom in`。押すたびに、画面の中心を保ったまま倍率が 4 パーセントポイントずつ変わります。パーセント表示は読み取り専用で、現在のモードの倍率を表示します。
- `Fit`。そのモードが表示するものすべてを画面に収めます。`Graph` ではすべてのノード、`Flow` ではすべてのカードです。
- `Tidy Up`。`Flow` でのみ表示され、カードを配置し直します。[Flow の配置](#how-flow-is-placed)を参照してください。
- 行の表示メニュー。`Flow` でのみ表示され、現在の選択肢がラベルになります。[行の表示](#row-display)を参照してください。
- `Show all`。`Flow` で、かつビューが絞り込まれている間だけ表示され、ダイアグラム全体に戻します。[テーブルへのフォーカス](#focusing-on-tables)を参照してください。
- `Go to content` コンパス。ノードもカードも画面にない間だけ、ツールバーの末尾に加わります。最も近いノードまたはカードを指す矢印と、`1.2k` のようなそこまでの距離を表示します。クリックすると、倍率を変えずにそのノードまたはカードを画面の中央に移動します。

拡大・縮小のボタンは、ツールチップにショートカットを表示します。例えば `Zoom in (Ctrl + Plus)` (Windows/Linux) または `Zoom in (⌘ + Plus)` (Mac) です。  
`Ctrl + Plus` と `Ctrl + Minus` (Windows/Linux) または `⌘ + Plus` と `⌘ + Minus` (Mac) は、どちらのモードでもボタンと同じように倍率を段階的に変え、`Ctrl + 0` (Windows/Linux) または `⌘ + 0` (Mac) は `100%` に直接戻します。  
リセットボタンはなく、クイック検索が開いている間はショートカットは動作しません。

## Graph モード {#graph-mode}

ドキュメント全体を力学モデルのグラフとして描画します。テーブル同士のつながりと、ドメインの中心にあるテーブルを一目で把握できます。

![Graph モードを開き、テーブルのプレビュー、ノードのドラッグ、縮小と拡大を行う](/img/demo-visualization.webp)

### グラフの読み方 {#reading-the-graph}

すべてのテーブルとカラムがノードになり、2 種類のノードは異なる色で描画されます。  
カラムのノードは、そのカラムが属するテーブルと線でつながり、リレーションシップで結ばれた 2 つのテーブルも互いに線でつながります。  
同じ方向のリレーションシップが複数あるテーブル同士は 1 本だけつながり、開始と終了が同じテーブルのリレーションシップは線を描画しません。

拡大していくとグラフ上にテーブル名が現れ、`50%` から `100%` の間で徐々に濃くなります。15 文字を超える名前は切り詰められます。カラムのノードはどの倍率でもラベルを持ちません。

### グラフの移動 {#getting-around-the-graph}

ホイールで、ポインタが指している位置を中心に `10%` から `400%` まで拡大・縮小します。  
トラックパッドのピンチでも同じように拡大・縮小します。タッチスクリーンでは 2 本の指で、指の間の位置を中心に拡大・縮小でき、指を動かすと表示位置も移動します。  
背景をドラッグすると表示位置が移動します。

[ツールバー](#toolbar)の拡大・縮小のボタンと拡大・縮小のショートカットは、代わりに画面の中心を保ったまま同じ範囲で拡大・縮小し、`Fit` はすべてのノードを画面に収めます。

### ホバープレビュー {#hover-preview}

テーブルのノードにマウスを重ねると、そのテーブルをカーソルの横にプレビューします。  
カラムのノードに重ねた場合は、ノードの周りに輪が描かれるだけで、プレビューは開きません。

プレビューは ERD キャンバスと同じカラムを同じ順序で表示します。[テーブルの表示オプション](./table-related-functions.md#table-view-options)と[カラム順の調整](./settings.md#adjusting-column-order)を参照してください。  
表示専用で、ノードや背景をドラッグしている間は非表示になります。

### 近傍の強調 {#highlighting-a-neighbourhood}

テーブルにマウスを重ねると、その近傍も一緒に明るくなります。テーブル自身、そのカラム、リレーションシップでつながる双方向のテーブル、そしてそれらを結ぶ線です。  
それ以外は薄くなるため、そのテーブルが何と接しているかがそのまま読み取れます。

### ノードの移動 {#moving-nodes}

ノードをドラッグすると、そのノードと、つながっているすべてのノードが新しい位置へ移動します。  
押している間はノードがポインタに固定され、その周囲のレイアウトが再び活発になります。  
ドラッグを終えるとレイアウトは再び落ち着き、ドロップした位置にノードが固定されることはありません。

### グラフはスナップショット {#the-graph-is-a-snapshot}

グラフはこのタブを開いた時点のドキュメントから構築され、タブに戻るたびに最初から再構築されます。  
`Flow` から `Graph` に切り替えたときも再構築され、再構築のたびに `100%` から始まります。

## Flow モード {#flow-mode}

すべてのテーブルをカードとして描画し、リレーションシップに沿ってカードを並べます。メモは描画されません。  
これは[自動レイアウト](./table-related-functions.md#auto-layout)の `Flow` レイアウトとは別物です。自動レイアウトは ERD タブのテーブルそのものを動かします。

各カードは ERD タブのテーブルと同じように描画されます。左端に沿ってテーブルの色があり、テーブルのアイコンとテーブル名が入ったヘッダーの帯、その下に[行の表示](#row-display)に応じた行が続きます。ERD タブのテーブルとは違い、カードは行の間に区切り線も描きます。カードはどの倍率でもこの見た目を保ち、ERD タブのテーブルが `70%` 以下でそうなるように名前だけの表示に縮むことはありません。カード上のものは何も編集できません。

コネクタはテーブルからテーブルへの 1 本のなめらかな曲線で、カードの下に描画されるため、カードの裏側を通ることがあります。コネクタは識別リレーションシップかどうかにかかわらず、すべて同じ灰色の実線で描画され、端の記号は ERD タブと同じです。[コネクタの読み方](./relationship-editing.md#reading-a-connector)を参照してください。Flow は `Relationship` の[表示オプション](./table-related-functions.md#table-view-options)がオフでもコネクタを描画します。

ダイアグラム全体を表示しているときは、リレーションシップでほかのテーブルとつながっていないテーブルが、ほかのテーブルの間に散らばらず、1 つのブロックにまとめられます。

![Flow に切り替えてカードの強調を固定し、Keys only を選んでから拡大して Fit を押す](/img/demo-visualization-flow.webp)

### 行の表示 {#row-display}

[ツールバー](#toolbar)の行の表示メニューで、各カードをどこまで描画するかを設定します。ラベルは現在の選択肢で、ツールチップは例えば `Row display: Name only` のように表示されます。  
メニューはツールバーの上に開き、現在の選択肢の横にチェックが付きます。選択肢を選ぶ、ラベルをもう一度クリックする、エディタ内のほかの場所をクリックする、`Escape` を押す、`Graph` に切り替える、のいずれかで閉じます。

| 行の表示 | 各カードに表示される内容 |
| --- | --- |
| `Name only` | ヘッダーのみ。 |
| `Keys only` | 主キーと外部キーのカラムに加え、リレーションシップが接続するその他のカラム。 |
| `All fields` | すべてのカラム。 |

行はテーブルのカラムの順に並びます。各行にはカラム名が表示され、主キー、外部キー、またはその両方であるカラムでは名前の前に鍵のアイコンが付きます。右側にはデータ型が表示されますが、これはカードが[明るい状態](#lighting-related-tables)の間だけ現れます。  
ほかのセルは描画されず、[テーブルの表示オプション](./table-related-functions.md#table-view-options)も、行内のセルの順序を決める[カラム順の調整](./settings.md#adjusting-column-order)も、カードには適用されません。

Flow を初めて開いたときは `Name only` で始まり、[テーブルへのフォーカス](#focusing-on-tables)で開いた場合は `Keys only` で始まります。その後は、別の選択肢を選んだときにだけ行の表示が変わり、ビューを絞り込んだり広げたりしても保たれます。  
行の表示を変えるとカードのサイズが変わるため、Flow はカードを配置し直して画面に収めます。

### Flow の移動 {#getting-around-the-flow}

ホイールで表示位置が移動し、`Shift + Wheel` では左右に移動します。`Ctrl + Wheel` (Windows/Linux) または `⌘ + Wheel` (Mac) では、画面の中心を保ったまま拡大・縮小します。  
トラックパッドのピンチでは、ピンチした位置を中心に拡大・縮小します。タッチスクリーンでは 2 本の指で、指の間の位置を中心に拡大・縮小でき、指を動かすと表示位置も移動します。  
背景をドラッグすると表示位置が移動します。ERD キャンバスと同じく、移動できる範囲に制限はありません。  
拡大・縮小のレベルは `10%` から `150%` までです。Flow は ERD タブとは別に独自の倍率と表示位置を持ち、どちらもドキュメントには保存されません。

背景を押すと選択が解除され、背景で `Ctrl + drag` (Windows/Linux) または `⌘ + drag` (Mac) すると選択範囲を描けます。  
Flow にはミニマップもスクロールバーもありません。移動した結果カードが画面に残らなくなったときは、[ツールバー](#toolbar)の `Go to content` コンパスを使います。

### 関連テーブルの強調 {#lighting-related-tables}

カードにマウスを重ねると、そのカード、そこからリレーションシップ 1 つでつながるテーブル、そしてそのカードとそれらのテーブルを結ぶコネクタが明るくなります。それらのテーブル同士を結ぶコネクタは明るくなりません。  
明るくなったカードにはアクセントカラーの枠線と光彩が付き、データ型が徐々に現れ、リレーションシップが接続する行に色が付きます。明るくなったコネクタはアクセントカラーに変わります。  
[Graph](#highlighting-a-neighbourhood) とは異なり、それ以外が薄くなることはなく、マウスを重ねたカードも固定したカードもない間は何も明るくなりません。

カードをクリックすると明るい状態が固定され、ポインタが離れても明るいままになります。同じカードをもう一度クリックするか、背景をクリックすると固定が解除され、別のカードをクリックすると固定がそのカードに移ります。マウスを重ねているカードと固定したカードは同時に明るくなります。  
ドラッグ、`Ctrl + click` (Windows/Linux) または `⌘ + click` (Mac)、表示位置の移動、[カードのボタン](#card-buttons)では、カードは固定も解除もされません。

明るくなったすべてのコネクタに沿って、主キーのある親テーブル側の端から子テーブル側の端へパーティクルが流れます。一度に 60 本を超えるコネクタが明るくなると、パーティクルは止まり、明るさはそのまま残ります。

### カードのボタン {#card-buttons}

ポインタがカードの上にある間は、ヘッダーの右端に、どちらもツールチップのない 2 つのアイコンボタンが表示されます。

- ウェイポイントのアイコンは `Flow` ボタンと同じもので、Flow をそのテーブルと、そこからリレーションシップ 1 つでつながるテーブルに絞り込みます。[テーブルへのフォーカス](#focusing-on-tables)を参照してください。
- 外部リンクのアイコンは ERD タブに切り替えてそのテーブルだけを選択し、テーブルが画面に収まりきっていない場合は画面の中央までスクロールします。

どちらのボタンを押しても、その操作はボタンだけに向けられます。カードは選択されず、最前面にも移らないため、ウェイポイントのボタンを押してもそれまでの選択はそのまま残ります。

### カードの移動 {#moving-cards}

カードは、カードの 2 つのボタン以外のどの部分をつかんでもドラッグできます。  
カードを押すと選択され、`Ctrl + click` (Windows/Linux) または `⌘ + click` (Mac) で選択に追加され、選択中のカードをドラッグすると選択中のすべてのカードが移動します。選択は ERD タブと共通のため、ここで選択したものは ERD タブに戻っても選択されたままです。

カードが動くのは Flow の中だけで、そのテーブルは ERD タブ上の位置から動きません。  
移動したカードは、表示位置の移動、拡大・縮小、`Fit` を経ても同じ位置に留まります。タブを離れるか `Graph` に切り替えてから戻ったとき、また `Show all` で Flow がすでに持っているダイアグラム全体のレイアウトに戻ったときは、レイアウトが配置した位置に戻ります。新しいレイアウトでは、置いた位置を考慮したうえで改めて配置されます。[Flow の配置](#how-flow-is-placed)を参照してください。

### テーブルへのフォーカス {#focusing-on-tables}

ERD タブで 1 つ以上のテーブルを選択して `Alt + F` (Windows/Linux) または `⌥ + F` (Mac) を押すか、テーブルを右クリックして `Focus on this table` を選びます。  
Visualization タブが `Flow` で開き、それらのテーブルと、そのいずれかからリレーションシップ 1 つでつながるテーブルに、向きを問わず絞り込まれます。コネクタは、表示されているテーブル同士のものだけが描画されます。

右クリックしたテーブルが複数選択しているテーブルの 1 つである場合、項目は `Focus on selected tables` と表示され、選択全体にフォーカスします。選択の外にあるテーブルを右クリックすると、そのテーブルだけにフォーカスします。  
`Alt + F` は選択しているテーブルを対象とし、メモは含めません。テーブルを選択していない場合は何もせず、セルやメモを編集している間や、クイック検索、テーブルのプロパティ、Diff Viewer、自動レイアウトのプレビュー、Time Travel が開いている間は無視されます。

Flow の中では、ウェイポイントの[カードのボタン](#card-buttons)が、そのテーブル 1 つを対象に同じようにビューを絞り込みます。[ツールバー](#toolbar)の `Show all` でダイアグラム全体に戻ります。  
絞り込んだビューは単独でレイアウトされ、画面に収められます。タブを離れるか `Graph` に切り替えてから戻っても絞り込まれたままで、`Escape` でも広がりません。

![⌥ + F で orders にフォーカスし、カードのボタンで members に絞り込んでから Show all で戻す](/img/demo-visualization-focus.webp)

### Flow の配置 {#how-flow-is-placed}

`Flow` を初めて表示するとき、表示するテーブルはメインスレッドの外でレイアウトされ、結果が画面に収められます。  
レイアウトはエディタを開いている間保持されます。タブを離れるか `Graph` に切り替えてから戻ると、Flow はそのレイアウトを再利用し、倍率と表示位置も離れたときのままです。  
Flow はダイアグラム全体のレイアウトと絞り込んだビューのレイアウトを 1 つずつ持つため、そのレイアウトの元になったものが何も変わっていない限り、`Show all` は計算し直さずにダイアグラム全体のレイアウトに戻り、画面に収めます。

Flow は次の場合にカードを配置し直します。

- `Tidy Up` を押したとき。結果は画面に収められます。
- 行の表示を変えたとき、またはビューを別のテーブルに絞り込んだとき。結果は画面に収められます。
- テーブルやリレーションシップが追加または削除されたとき。離れている間に ERD タブで行われた変更は戻ったときに反映され、Flow にいる間に共同編集の参加者が行った変更も反映されます。倍率と表示位置はそのままです。

どのレイアウトもカードの現在の位置を考慮するため、`Tidy Up` を押しても以前の配置に戻るとは限りません。  
テーブル名の変更やカラムの追加のように、カードのサイズが変わるだけの変更ではカードは配置し直されません。カードが重なってしまった場合は `Tidy Up` を押します。

6 秒を超えるレイアウトでは、`Cancel` の付いた `Placing tables…` の通知が表示されます。  
`Cancel`、またはレイアウトの実行中にいつでも `Escape` を押すとレイアウトは破棄され、`Tidy Up` を押すか `Flow` に戻ると改めて要求されます。  
ホストが Shared Worker を動かさない、ワーカーの起動に失敗する、60 秒以内にレイアウトが返ってこない、といった理由でレイアウトに失敗すると、Flow は `Could not place tables` を表示し、`Tidy Up` で再試行します。[Web Worker](../../api/installation.md#web-workers) を参照してください。  
Flow はダイアグラム全体でも絞り込んだビューでも、最後のレイアウトが配置したテーブルだけを描画するため、初めて表示するときはレイアウトが成功するまでカードが 1 枚もないこともあります。  
ビューを別のテーブルに絞り込んだときなど、Flow がカードを配置し直すときは、新しいレイアウトが届くまで前の配置が画面に残り、そのレイアウトがキャンセルされたり失敗したりしても前の配置のままです。

ファイルの読み込みなどでドキュメント全体が置き換わると、Flow のレイアウト、フォーカス、行の表示、倍率、表示位置は破棄され、次に Flow を開いたときは初めて開いたときと同じように始まります。つまりダイアグラム全体で始まるか、[テーブルへのフォーカス](#focusing-on-tables)で開いた場合は絞り込まれた状態で始まります。

### Flow はドキュメントを編集しない {#flow-never-edits-the-document}

Flow はダイアグラムを読むだけです。拡大・縮小、表示位置の移動、カードの移動、`Tidy Up`、行の表示、固定、フォーカスは、どれも [Undo の履歴](./undo-redo.md#what-the-history-records)に何も追加しません。  
ダイアグラムにも何の変更も加えません。ただし、カードを押すと、ERD タブでテーブルをクリックしたときと同じようにそのテーブルが最前面に移るため、ERD タブでも前面に表示されます。`Graph` も同じようにダイアグラムには手を加えません。  
外部リンクの[カードのボタン](#card-buttons)は Flow の外へ移動するため、さらに一歩踏み込みます。ERD タブで行うスクロールは、ほかの表示位置の変更と同じように記録されます。

Flow にいる間も共同編集の参加者の編集はダイアグラムに届き、カードは参加者が追加・削除したテーブルとリレーションシップに追従します。[Flow の配置](#how-flow-is-placed)を参照してください。  
参加者の選択とフォーカスの枠はカードに描画されますが、マウスカーソルとドラッグボックスは描画されません。[共同編集](../../api/advanced/collaborative-editing.md)を参照してください。

フォーカスを含め、どちらのモードも `readonly` のエディタでも動作します。
