# 論理名

テーブルとその各カラムは、名前とは別に論理名を持てます。論理名は人が読むための名前で、例えば `CUST_NM` に対する `Customer Name` のようなものです。名前そのものが物理名で、[Schema SQL](./schema-sql.md) と[コード生成](./code-generator.md)が書き出すのはこちらです。  
名前の表示は、ERD キャンバスが名前、論理名、その両方のどれを描くかを決めます。[名前の表示](#name-view)を参照してください。  
論理名からは、[辞書](./dictionary.md)タブの単語と用語をもとに、そのテーブルやカラムの物理名を生成することもできます。[物理名の生成](./dictionary.md#deriving-physical-names)を参照してください。  
カラムはドメインに紐付けられます。ドメインは辞書タブの `Domains` シートに登録された名前の付いたデータ型で、例えば `VARCHAR(100)` に対する `Name` のようなものです。紐付いたカラムは、そのドメインのデータ型を持ちます。[ドメインのセル](#the-domain-cell)を参照してください。  
Schema SQL は、各論理名を空のコメントに書き出せます。[コメントとしての論理名](./schema-sql.md#logical-names-as-comments)を参照してください。

## 名前の表示 {#name-view}

表示は 3 つあり、テーブルのヘッダーと行の描き方がそれぞれ異なります。

- `Physical Names` は新しいダイアグラムの表示で、論理名を描画しません。ヘッダーにはテーブルの名前と、View Option → `Table Comment` がオンの間はそのコメントが表示され、各行には[カラム順](./settings.md#adjusting-column-order)にセルが表示されます。
- `Logical Names` は、各名前の代わりに論理名を描画します。対象はヘッダーと、各行のカラム順で `Name` がある位置です。行の型のセルは、後述のように、カラムのドメインを表すことがあります。
- `Both Names` は、名前の横に論理名を描画します。ヘッダーには論理名、名前、コメントの順に表示され、各行には `Logical Name` のセルが加わります。このセルは、既定ではカラム順で `Name` の直前に置かれます。

空の論理名（空白だけのものを含む）には、代わりの表示が淡い色で表示されます。`Logical Names` では、代わりに描画される名前がそれにあたり、名前も空の場合はプレースホルダーの `table` または `column` です。`Both Names` では、プレースホルダーの `logical` です。

`Logical Names` では、辞書タブの `Domains` シートにある名前の付いたドメインに紐付いたカラムは、型のセルにデータ型ではなくそのドメインの名前を表示します。それ以外のカラムは、そこにデータ型を表示します。  
View Option → `Domain` がオンの間は、ドメインに専用のセルがあり、型のセルはデータ型のままなので、ドメインを 2 回表示する行はありません。[ドメインのセル](#the-domain-cell)を参照してください。

各テーブルの幅は、その表示で描画するセルに合わせて決まるため、表示を切り替えるとテーブルのサイズが変わり、コネクタが配置し直されます。テーブルは移動しません。  
`70%` 以下では、テーブルは名前だけの表示に折りたたまれます。[拡大・縮小](./table-related-functions.md#拡大縮小)を参照してください。`Logical Names` では論理名を表示し、論理名がない間は名前を淡い色で表示します。`Both Names` では論理名と、その下の行に名前を表示し、論理名がない間は名前だけを表示します。

辞書のチェックは、検出した論理名や名前を赤またはアンバーで表示することがあります。[キャンバス上のマーク](./dictionary.md#marks-on-the-canvas)を参照してください。

## 表示の切り替え {#switching-the-view}

表示を切り替えられる場所は 4 つあり、どれも `Physical Names`、`Logical Names`、`Both Names` を並べ、現在の表示にチェックが付きます。

- [キャンバスツールバー](./table-related-functions.md#canvas-toolbar)の `Name View` ボタン。4 種類のリレーションシップ記法と Zen モードの間にあります。ボタンには現在の表示の名前と下向きの矢印が表示され、ツールチップには `Name View` と表示されます。クリックするとツールバーの上に一覧が開き、選ぶと閉じます。
- キャンバスのコンテキストメニューの `Name View`。`View Option` のすぐ後にある、3 つの表示のサブメニューです。選んだ後もメニューは開いたままです。
- `Flow` モードの Visualization タブのツールバーにある同じ一覧。行の表示メニューの後にあります。[ツールバー](./visualization.md#toolbar)を参照してください。
- [クイック検索](./quick-search.md#パレットに表示される内容)の `Name View`。`Tab` のすぐ後にあり、ERD タブでのみ表示されます。サブメニューは、現在の表示がハイライトされた状態で開きます。

![キャンバスツールバーから名前の表示を Logical Names に、キャンバスのメニューから Both Names に切り替えて Physical Names に戻し、論理名のない ordered_at が淡い色で、続いてプレースホルダーの logical として表示される様子](/img/demo-name-view.webp)

4 つとも同じ表示を設定します。上部のツールバーには、そのためのボタンはありません。

切り替えても選択はそのままで、[Undo の履歴](./undo-redo.md#what-the-history-records)には記録されません。  
フォーカスしているセルが新しい表示で描画されない場合、フォーカスは代わりに描画されるセルに移動します。名前と論理名は互いの代わりになり、型とドメインも同様です。そのセルを編集中であれば、編集は終了します。View Option → `Domain` をオンまたはオフにしたときも、同じようにフォーカスが移動します。  
`Name View` のロックがオンの間は（新しいダイアグラムではオンです）、切り替えは自分の画面だけを変え、ファイルはロックしたときの表示を保ちます。ロックがオフの場合は、切り替えた表示がファイルに保存されます。[ロック](./settings.md#ロック)を参照してください。

## 論理名の入力 {#writing-a-logical-name}

`Physical Names` は論理名を描画しないため、キャンバスで論理名を入力するには `Logical Names` または `Both Names` に切り替えます。

- `Logical Names` では、ヘッダーと行の名前のセルが論理名を持つため、この表示ではキャンバスで物理名を編集できません。
- `Both Names` では、論理名のセルが論理名を、名前のセルが物理名を持ちます。

論理名のセルは、ほかのセルと同じように編集します。`Enter` またはダブルクリックで開始します。[テーブルの編集](./table-editing.md)を参照してください。空の論理名で開くと、入力欄にはセルが描画していたものがプレースホルダーとして表示されます。`Logical Names` では名前、`Both Names` では `logical` です。  
入力で書き換わるのは論理名だけです。論理名を変更して入力欄を閉じると（`Enter`、`Tab`、`Escape`、またはほかの場所のクリック）、その論理名から物理名が生成されます。これは、入力に続く独立した Undo の 1 ステップになります。自分で付けた物理名はそのまま残ります。[物理名の生成](./dictionary.md#deriving-physical-names)を参照してください。

`Tab` と `Shift + Tab` は、その表示が描画するセルを、次の順序でたどります。[Tab キー](./table-editing.md#tab-キー)を参照してください。

- `Logical Names` では、ヘッダーの論理名、コメント、続いて各行のセルをカラム順にたどり、名前の位置には論理名があります。
- `Both Names` では、ヘッダーの論理名、名前、コメント、続いて各行のセルをカラム順にたどり、既定では `Logical Name` のセルが最初です。

`Alt + Enter` (Windows/Linux) または `⌥ + Enter` (Mac) はカラムを追加し、その名前のセルにフォーカスします。`Logical Names` では、このセルは論理名のセルです。

リレーションシップが追加する外部キーカラムは、キーのデータ型とともに、キーの論理名とドメインもコピーします。[識別リレーションシップ](./relationship-editing.md#識別リレーションシップ)を参照してください。  
スプレッドシートへのカラムのコピーと、スプレッドシートからのカラムの貼り付けには、論理名とドメインのセルを含め、その表示が描画するセルが使われます。[カラムのコピー / 貼り付け](./table-editing.md#カラムのコピー--貼り付け)を参照してください。

## 用語名の補完 {#completing-term-names}

ヘッダーまたは行の論理名のセルに入力している間は、セルの下の一覧に、名前が入力した文字列で始まる用語が候補として表示されます。大文字と小文字は区別せず、文字列の前の空白も無視します。用語は辞書タブの `Terms` シートに登録された論理名全体で、その用語が与える物理名とドメインを伴います。一覧には名前順に最大 8 件が表示され、入力した文字列がハイライトされます。そのように始まる用語がない間は、一覧は表示されません。

![Both Names で ⌥ + Enter によりカラムを追加し、論理名の下の用語の候補一覧から Order Amount を選んで ORD_AMT、DECIMAL(10,2)、Amount ドメインを入力し、続いて Order Date を入力して、Enter で入力欄を閉じると単語から名前 ORD_DT が生成される様子](/img/demo-logical-names.webp)

- 最初は何もハイライトされていません。`↑` と `↓` でハイライトが移動し、両端で折り返します。ハイライトされた用語には `Enter` キーが表示されます。
- 用語がハイライトされているときに `Enter` を押すと、その名前を論理名として書き込み、編集を終了します。物理名が自分で付けたものでない限り、同じ Undo の 1 ステップで、すぐにその用語から物理名を生成し、カラムには用語のドメインも紐付けます。何もハイライトされていないときに `Enter` を押すと、入力した内容をそのまま残して編集を終了します。
- 用語をクリックすると、同じように書き込み、入力欄は開いたままです。
- 一覧が表示されている間に `Escape` を押すと一覧だけが閉じ、次の `Escape` で編集を終了します。
- `Tab` は入力したとおりの文字列のまま次へ移動し、入力欄が閉じるときにその文字列から物理名が生成されます。
- IME の変換中は、矢印キーと `Enter` は変換に使われます。

用語がテーブルやカラムに与えるものについては、[物理名の生成](./dictionary.md#deriving-physical-names)を参照してください。

## ドメインのセル {#the-domain-cell}

View Option → `Domain`（既定でオフ）をオンにすると、どの表示でも各行にドメインのセルが加わります。位置はカラム順で `Domain` がある場所で、既定では `DataType` の直後です。[テーブルの表示オプション](./table-related-functions.md#table-view-options)を参照してください。  
このセルには、カラムが紐付いているドメインの名前が表示されます。`Domains` シートにあるどのドメインにも紐付いていないカラムでは、プレースホルダーの `domain` が淡い色で表示されます。

![View Option → Domain をオンにし、PAY_AMT のドメインのセルで amo と入力して一覧を絞り込んでから Amount を選び、辞書タブで Amount の Data Type を DECIMAL(12,2) に変更してカラムも一緒に変わったことを確かめ、続いてカラムに NUMERIC(12,2) を入力して紐付けが解除される様子](/img/demo-domains.webp)

`Enter` またはダブルクリックで、セルの上にピッカーが開きます。セルのテキストをプレースホルダーにした空のフィールドがあり、その下に `None`、続いて `Domains` シートにある名前の付いたすべてのドメインがシートの順に並びます。ハイライトは、紐付いているドメイン、または `None` から始まります。

- 入力すると、名前にその文字列を含むドメインだけが一覧に残り（大文字と小文字は区別しません）、`None` が外れて、最初のドメインがハイライトされます。`↑` と `↓` でハイライトが移動します。
- `Enter` はハイライトされているドメインを紐付け、クリックするとクリックしたドメインを紐付けます。どちらも Undo の 1 ステップとしてカラムにドメインのデータ型を設定し、編集を終了します。`None` はカラムの紐付けを解除し、データ型はそのまま残します。
- 入力した文字列がカラムに書き込まれることはありません。`Domains` シートに名前の付いたドメインがない間は一覧がなく、`Enter` は何も書き込まずに編集を終了します。

View Option → `Domain` がオフの `Logical Names` では、ドメインの名前を表示している型のセルはこのピッカーを開き、データ型を表示している型のセルはデータ型の入力欄を開きます。[DataType の自動補完](./table-editing.md#datatype-の自動補完)を参照してください。ドメインのないカラムにドメインを紐付けるには、ドメインのセルをオンにします。  
紐付いたカラムはドメインのデータ型を持ち、ドメインの型が変わるとそれに従います。DataType のセルに別の型を入力すると、紐付けが解除されます。[ドメインとデータ型](./dictionary.md#domains-and-data-types)を参照してください。

## キャンバスの外 {#beyond-the-canvas}

テーブルやカラムの名前を表示するほかの場所も、ほとんどが名前の表示に従います。

- `Physical Names` では名前を表示します。
- `Logical Names` では論理名を表示し、論理名が空の間は名前を表示します。名前は、淡い色で表示できる場所では淡い色になります。
- `Both Names` では論理名と、その後に名前を表示します。名前は、テキストの行では淡い色で、Graph のラベルでは 2 行目に、1 つのテキストに両方を収める必要がある場所では `Member (member)` のように括弧に入れて表示されます。論理名のないテーブルやカラムは、名前だけを表示します。

エクスプローラーのテーブルやクイック検索の `#` の行のように名前順に並ぶ一覧は、どの表示でも名前順のままで、論理名順になることはありません。

表示に従う場所は次のとおりです。

- Visualization タブの Flow のカード（[カードの名前](./visualization.md#names-on-the-cards)を参照）と、Graph のラベルとホバープレビュー（[グラフの読み方](./visualization.md#reading-the-graph)と[ホバープレビュー](./visualization.md#hover-preview)を参照）。
- [テーブルのプロパティ](./table-related-functions.md#table-properties): チップと、`Indexes` タブの `Columns` の行と `Index order` の一覧。[インデックス](./table-related-functions.md#indexes)を参照してください。
- [エクスプローラー](./explorer.md#the-tree)のテーブルとカラムの行、および各テーブルグループの下に表示されるテーブル。
- クイック検索の `#` の行。[ダイアグラムの検索](./quick-search.md#searching-the-diagram)を参照してください。
- [Diff Viewer](./table-related-functions.md#diff-viewer) の変更のツリーと、その両側。
- [Map Columns](./relationship-editing.md#map-columns) と、リレーションシップを描いている間に `Create new columns` が表示することのある `<parent> has no primary key to copy` のツールチップ。[リレーションシップの作成](./editing-start.md#リレーションシップの作成)を参照してください。
- カラムをドラッグしている間、空いているキャンバスの上で運ばれる行のコピー。各行の名前と型のセルを、その行が描画しているとおりに表示します。[カラムの並べ替えと移動](./table-editing.md#カラムの並べ替えと移動)を参照してください。
- 辞書タブの `Checks` シートの `Target` 列。[Checks シート](./dictionary.md#the-checks-sheet)を参照してください。
- [書き出した画像](./file-import-export.md#画像)。

いくつかの場所は、表示にかかわらず名前を表示します。エクスプローラーのインデックスと外部キーの行、テーブルのプロパティの `Indexes` タブにある `Keys`、Map Columns の `New column: <name>`、クイック検索の `@` または `:` の行の横に表示される場所です。

Diff Viewer、[Time Travel](./undo-redo.md#time-travel)、[自動レイアウト](./table-related-functions.md#auto-layout)の `Force` のプレビュー、`Export image` ダイアログは、ファイルが保持する表示にかかわらず、画面で見ている名前の表示で開きます。どれも、開いている間はその表示を保ちます。  
すべての自動レイアウトと、Schema SQL、GraphQL、DBML、AML の `Import` または `Import and Add` は、自分の表示でのテーブルの幅でテーブルを配置します。

## 論理名での検索 {#finding-by-logical-name}

論理名は、キャンバスが論理名を描画しない `Physical Names` を含め、どの名前の表示でも検索できます。

- [検索と置換](./find-and-replace.md#what-it-searches)は、テーブルとカラムの論理名を 1 種類のテキスト `Logical names` として検索し、検索を初めて開いたときはこれがオンになっています。論理名を置換すると、入力したときと同じように、その論理名から物理名が生成されます。
- [クイック検索](./quick-search.md#searching-the-diagram)では、`#` はテーブルを名前または論理名で、`@` はカラムをそのどちらかで検索し、論理名で一致した結果には横に `Logical name` と表示されます。`@` のテーブルの部分（`.` より前）も、テーブルの名前または論理名に一致します。

名前の表示を切り替えると、結果に表示される名前は変わりますが、見つかるものは変わりません。

## 共同編集者 {#collaborators}

[共同編集のセッション](../../api/advanced/collaborative-editing.md)では、論理名とドメインの紐付けは、ほかの編集と同じようにすべてのエディタに届きます。  
`Name View` のロックがオンの間は、各エディタが独自の表示を保ち、切り替えは切り替えたエディタにだけ反映されます。オフの間は、読み取り専用でないどのエディタで切り替えても、すべてのエディタが切り替わります。[ロック](./settings.md#ロック)を参照してください。ロックをオンまたはオフにしたときに各エディタの表示がどうなるかも、そこで説明しています。  
参加者がフォーカスしているセルが自分の表示で描画されないセルの場合、その参加者の色は、自分の表示でその代わりに描画されるセルに表示されます。`Physical Names` での名前のセルは `Logical Names` での自分の論理名のセルに表示され、その逆も同様です。型のセルと、その代わりになるドメインも同じように対応します。

MCP サーバーを通じて作業するコーディングエージェントは、画面で見ている表示にかかわらず論理名を設定し、ドメインを紐付けます。名前の表示を切り替えるツールはありません。MCP のツールの[辞書](../../mcp/tools.md#dictionaries)と[設定](../../mcp/tools.md#settings)を参照してください。

## 読み取り専用のエディタ {#read-only-editors}

[`readonly`](../../api/erd-editor-element.md#readonly) のエディタでは、名前の表示を選ぶピッカーはどれも動作し、ロックにかかわらず、切り替えはその画面だけを変えます。  
そこでは論理名とドメインを編集できないため、用語の候補一覧もドメインのピッカーも開かず、`Derive Physical Name Again` と `Derive Physical Names Again` の項目はどれも表示されません。ほかの[表示オプション](./table-related-functions.md#table-view-options)と同じく、View Option → `Domain` もそこでは何も変えません。
