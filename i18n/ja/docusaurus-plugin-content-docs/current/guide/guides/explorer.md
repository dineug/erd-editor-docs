# エクスプローラー

エクスプローラーは ERD キャンバスの左端にドッキングされたパネルで、ダイアグラムをツリーとして一覧表示します。テーブルとそれぞれのカラム、インデックス、外部キー、続いて[テーブルグループ](./table-groups.md)、最後にメモが並びます。行をクリックすると、その行が表すキャンバス上の対象へ移動します。  
エクスプローラーはキャンバスを覆うのではなく、キャンバスの幅を狭めます。これはダイアグラムエディタの一部で、VS Code のエクスプローラービューや Obsidian のファイルエクスプローラーとは別のものです。

![ツールバーからエクスプローラーを開き、products へ移動してから、orders の status カラムと member_id の外部キーへ移動し、Collapse All で折りたたんで、パネルを広げてから閉じる様子](/img/demo-explorer.webp)

エクスプローラーの上部、タイトルバーとツリーの間には[検索と置換](./find-and-replace.md)があります。検索フィールドにテキストがある間は、ツリーには一致するものだけが表示されます。[検索結果](./find-and-replace.md#the-results)を参照してください。  
ツリー自体がダイアグラムを変更することはなく、名前の変更、ドラッグ、削除、表示と非表示の切り替えはできません。パネルが行う編集は置換だけです。

エクスプローラー自体の状態は、エディタを使う人だけのものです。開いているかどうか、幅、折りたたみの状態、キーボードの行、スクロールの位置、検索がこれに当たります。  
どれもファイルに保存されず、Undo の履歴にも記録されず、共同編集者とも共有されず、ブラウザにも保存されません。エディタが開いている間は保持され、タブを切り替えても、同じエディタに別のドキュメントを読み込んでも保たれます。新しく開いたエディタでは、エクスプローラーは閉じた状態で始まります。

## 開き方と閉じ方 {#opening-and-closing}

次のいずれかで開きます。

- ツールバーで `Search` のすぐ後にある、ツリーのアイコンの `Explorer` ボタン。ツールチップには `Explorer (Ctrl + F)` (Windows/Linux) または `Explorer (⌘ + F)` (Mac) と表示されます。
- `Ctrl + F` (Windows/Linux) または `⌘ + F` (Mac)。設定の[ショートカット](./settings.md#ショートカット)タブでは `Toggle Explorer` という名前です。
- [クイック検索](./quick-search.md)の `Toggle Explorer`。どのタブでも一覧に表示され、`find`、`replace`、`rename`、`tree`、`outline`、`objects` と入力すると見つかります。
- キャンバスのコンテキストメニューの `Toggle Explorer`。ERD キャンバスの空いている場所を、[テーブルグループ](./table-groups.md)の外側で右クリックすると表示されます。`New Table`、`New Memo`、`New Table Group` の後、`Relationship` の前にあります。

2 つの `Toggle Explorer` の項目は、右側にショートカットを表示します。  
ツールバーのボタン、ショートカット、クイック検索の項目は、どのタブからでも使えます。エクスプローラーは ERD タブでのみ表示されるため、Visualization、Schema SQL、Code Generator、設定の各タブから使うと、まず ERD タブに切り替わります。

ツールバーのボタンは、パネルを開閉するだけです。検索フィールドにキャレットを置くことはなく、テーブルのプロパティ、テーマビルダー、`Display Language` のピッカーも開いたままにします。  
ショートカットと 2 つの `Toggle Explorer` の項目は、エクスプローラーを検索の状態で開きます。検索フィールドにキャレットが移ってそのテキストが選択され、[エクスプローラーの横のダイアログ](#dialogs-beside-it)にある 5 つのダイアログのいずれかが開いていれば閉じます。開き直したときに検索が何を保つかについては、検索と置換の[開き方と閉じ方](./find-and-replace.md#opening-and-closing)を参照してください。  
テーブルのセル、メモ、テーブルグループの名前を編集している間は、ショートカットは何もしません。

エクスプローラーが ERD タブで開いていて、[Zen モード](#when-it-stands-aside)で隠れていない間は、ツールバーのボタンが押された状態で表示されます。その間は、ボタン、ショートカット、どちらの `Toggle Explorer` の項目でもエクスプローラーが閉じ、キーボード操作がパネル内にあった場合はエディタに戻ります。  
クイック検索か 5 つのダイアログのいずれかが開いている間は、ショートカットでエクスプローラーが閉じることはありません。代わりにパレットやダイアログを閉じて、キーボード操作を検索フィールドに移し、そのテキストを選択します。エクスプローラーがすでに表示されていた場合は、現在の一致箇所もそのまま保たれます。クイック検索の `Toggle Explorer` の項目にはこの例外はなく、実行するとパレットが閉じ、続いて開いているエクスプローラーも閉じます。

タイトルバーの `x` ボタンでもエクスプローラーが閉じ、キーボード操作はキャンバスに移ります。このボタンのツールチップには `Close` と表示されます。`Escape` では閉じません。[エクスプローラー内のキー](#keys-in-the-explorer)を参照してください。  
開き直すと、エクスプローラーは同じ幅で、ツリーの折りたたみとスクロールの位置も以前のまま、同じ検索語で再び表示されます。ショートカットか `Toggle Explorer` の項目で開いた場合は、その検索語であらためて検索し、すべての検索結果を展開して表示します。[検索結果](./find-and-replace.md#the-results)を参照してください。

エクスプローラーを表示するには幅が足りないエディタで、ショートカットか `Toggle Explorer` の項目でエクスプローラーを開くと、`Widen the window to show the Explorer` のトーストが表示され、キーボード操作は元の場所にとどまります。[キャンバスの横](#beside-the-canvas)を参照してください。  
それでもエクスプローラーは開いていて、ツールバーのボタンも押された状態になり、エディタの幅が十分になると、検索を済ませた状態で表示されます。このとき、キーボード操作は移りません。ツールバーのボタンで開いた場合は、トーストは表示されません。

## キャンバスの横 {#beside-the-canvas}

エクスプローラーは、ERD タブの左端に沿って、ツールバーの下からキャンバスの高さいっぱいに表示されます。  
キャンバスはその分だけ幅が狭まるため、ダイアグラムのどの部分もパネルの下に隠れることはなく、[キャンバスツールバー](./table-related-functions.md#canvas-toolbar)、ミニマップ、[ウェルカム画面](./editing-start.md#ウェルカム画面)もすべて、その横のキャンバスの中に収まります。  
エクスプローラーを開いたり、閉じたり、サイズを変えたりしても、ダイアグラムはスクロールせず、[Undo の履歴](./undo-redo.md#what-the-history-records)にも何も記録されません。

新しく開いたエディタでは、幅 `260px` で始まります。右端をドラッグすると `200px` から `480px` までの任意の幅に設定でき、その端をダブルクリックすると `260px` に戻ります。

キャンバスは、エクスプローラーの横に常に `320px` 以上の幅を確保します。

- エディタの幅がエクスプローラーの幅に `320px` を足した値より狭い場合、エクスプローラーは収まるように狭く描画され、最小で `200px` になります。
- エディタの幅が `520px` より狭い場合、エクスプローラーは退きます。描画はされませんが開いたままのため、ツールバーのボタンは押された状態で表示され、押すとエクスプローラーが閉じます。エディタの幅が十分になると、エクスプローラーは元の幅で再び表示されます。

[開き方と閉じ方](#opening-and-closing)のトーストはウィンドウと表現していますが、基準になるのはブラウザのウィンドウではなく、エディタ自体の幅です。

[右から左に書く表示言語](./language-and-theme.md#右から左に書く言語)でも、キャンバスは左右反転しないため、エクスプローラーはキャンバスの左にとどまります。  
内側は右から左に読む向きになります。タイトルバー、検索、行は左右反転し、行は右からインデントされます。ドラッグする端は、キャンバスに接する右側のままです。データ型、インデックスのカラム、外部キーのテキストは、左から右の順序を保ちます。

## エクスプローラーが隠れるとき {#when-it-stands-aside}

エクスプローラーは ERD タブでのみ表示されます。  
ほかのタブに切り替えるとエクスプローラーは隠れ、ツールバーのボタンも押された状態ではなくなります。ERD タブに戻ると、離れたときと同じ折りたたみとスクロールの位置で再び表示されます。

[Diff Viewer](./table-related-functions.md#diff-viewer)、[Time Travel](./undo-redo.md#time-travel)、[自動レイアウト](./table-related-functions.md#auto-layout)のプレビューのいずれかが開いている間は、どの方法でもエクスプローラーを開閉できません。

- 開いているエクスプローラーは隠れ、それらが閉じると再び表示されます。
- ツールバーのボタンは淡色表示になって何もしません。
- クイック検索には `Toggle Explorer` が表示されません。
- ショートカットはブラウザまたはホストに渡されます。[ブラウザの検索バー](./find-and-replace.md#the-browsers-find-bar)を参照してください。

Diff Viewer は、同じ種類のツリーに変更点を一覧表示します。[Diff Viewer](./table-related-functions.md#diff-viewer) を参照してください。

`Alt + Z` (Windows/Linux) または `⌥ + Z` (Mac) で [Zen モード](./table-related-functions.md#canvas-toolbar)をオンにすると、開いているエクスプローラーは閉じずに隠れ、Zen モードをオフにするとエクスプローラーが再び表示されます。  
Zen モードでも、ショートカットと 2 つの `Toggle Explorer` の項目はエクスプローラーを検索の状態で開き、Zen モードはオンのままです。このとき上部のツールバーがないため、エクスプローラーはエディタの高さいっぱいに表示され、Zen モードをオフにしても表示されたままです。Zen モードを再びオンにすると、また隠れます。

キーボード操作がパネル内にある状態でパネルが見えなくなると、閉じた場合も、隠れた場合も、退いた場合も、キーボード操作はエディタに戻ります。

## ツリー {#the-tree}

タイトルバーには `Explorer` と表示され、`Collapse All` と、エクスプローラーを閉じる `x` の 2 つのボタンがあります。その下に検索、さらにその下にツリーがあります。検索については[検索と置換](./find-and-replace.md)を参照してください。

最上位には `Tables`、`Table Groups`、`Memos` の 3 つのフォルダがこの順に並びます。各テーブルの下には、そのテーブル自身の `Columns`、`Indexes`、`Foreign Keys` のフォルダがあります。  
中身のないフォルダは表示されないため、空のダイアグラムでは行が 1 つも表示されません。また、[View Option](./table-related-functions.md#table-view-options) → `Table Groups` でグループを非表示にしている間は `Table Groups` が、View Option → `Memos` でメモを非表示にしている間は `Memos` が表示されません。  
フォルダの行には、フォルダのアイコン、名前、そして末尾にそのすぐ下にある行の数が表示されるため、`Tables` の横の数はダイアグラムのテーブルの数です。

テーブルは大文字と小文字を区別せずに名前順に並び、同じ名前のテーブルはドキュメントの順序を保ちます。テーブルグループも、各グループの下のテーブルも同じように並びます。テーブルのカラムはそのテーブル自体の順序を保ち、インデックス、外部キー、メモはドキュメントの順序を保ちます。  
ツリーは、キャンバスでの編集、Undo や Redo、読み込み、共同編集者やコーディングエージェントによる変更のいずれでも、ダイアグラムの変更に追従します。そのため、テーブルの名前を変更するとその行の位置が変わります。

各種類の行には、次のものが表示されます。

- テーブル: テーブルのアイコンと名前。
- カラム: 主キーまたは外部キーのカラムにはキーのアイコンが付き、テーブル自体のキーのセルが主キー、外部キー、その両方に付けるのと同じ色になります。それ以外のカラムにはリストのアイコンが付きます。続いて名前と、淡い色でデータ型、その後に `PK`、`FK`、またはその両方が表示されます。`id` `BIGINT PK` や `user_id` `BIGINT FK` のようになります。
- インデックス: インデックスのアイコンと名前。続いて淡い色で、ユニークインデックスでは `UNIQUE`、そしてそのカラムがインデックスの順序で括弧の中に表示され、降順のカラムの後には `DESC` が付きます。`orders_user_idx` `UNIQUE (user_id DESC, total)` や、単に `(total)` のようになります。
- 外部キー: 外部キーのカラムを持つ子テーブルの下にだけ、親テーブルがダイアグラムにある間だけ一覧表示されます。キーのアイコンはコネクタの色になり、[識別リレーションシップ](./relationship-editing.md#識別リレーションシップ)では主キーかつ外部キーの色、それ以外では外部キーの色です。子テーブルのキーのカラムがカンマ区切りで表示され、続いて淡い色で `→` と親テーブルとそのカラムが表示されます。`user_id` `→ users(id)` のようになります。
- テーブルグループ: グループの色の点（色のないグループでは灰色）と名前。その下にグループのテーブルが名前順に並び、それぞれそのテーブルへ移動します。テーブルのないグループには、展開するものがありません。
- メモ: 付箋のアイコンとメモの最初の行。

空の名前と、最初の行が空のメモは、斜体の `unnamed` と表示されます。  
パネルの幅が狭い場合は、名前より先に淡い色のテキストが `…` で省略されます。名前や淡い色のテキストにマウスを重ねると、全体が表示されます。

最初は `Tables` だけが展開されています。フォルダの行をクリックするか、その行で `Enter` か `Space` を押すと、折りたたまれるか展開されます。  
行の先頭にある矢印は、どこにも移動せずにその行を折りたたむか展開します。下に何もないテーブルを含め、すべてのテーブルの行にこの矢印があります。`→` と `←` でも折りたたみと展開ができます。[エクスプローラー内のキー](#keys-in-the-explorer)を参照してください。  
`Collapse All` は、押すたびに 1 階層ずつ折りたたみます。対象は表示されている展開済みの行のうち最も深い階層のため、押すごとに下の階層から順に折りたたまれます。最上位の階層に達した押下では、すでに折りたたまれた行の下にある行も含めてすべての行が折りたたまれ、最上位のフォルダだけが残ります。  
編集、Undo と Redo、共同編集者やコーディングエージェントによる変更では、折りたたみの状態は変わりません。

## 行への移動 {#going-to-a-row}

行をクリックするか、キーボードでその行にいるときに `Enter` か `Space` を押すと、その行が表す ERD キャンバス上の対象へ移動します。フォルダの行は折りたたまれるか展開されるだけで、矢印キーはツリーの中を移動するだけです。

- テーブルの行、またはグループの下に並ぶテーブルは、そのテーブルだけを選択して最前面に移します。フォーカスがすでにそのテーブルの中にある場合を除き、テーブル名にフォーカスします。
- カラムの行は、そのテーブルだけを選択し、カラム名にフォーカスします。
- インデックスの行は、テーブルの行と同じようにそのテーブルを選択します。インデックス自体が個別に示されることはありません。インデックスは[テーブルのプロパティ](./table-related-functions.md#indexes)で編集します。
- 外部キーの行は、リレーションシップの両方のテーブルを一緒に表示し、2 つが離れすぎていて一緒に表示できない場合は子テーブルを表示します。子テーブルだけをその外部キーのカラムとともに選択して、最初のカラムにフォーカスし、リレーションシップのコネクタを強調表示します。[コネクタの読み方](./relationship-editing.md#reading-a-connector)を参照してください。
- テーブルグループの行は、グループの枠をタイトルバーを基準に表示し、そのグループだけを選択して、そのテーブルとともに最前面に移します。
- メモの行は、そのメモだけを選択して最前面に移します。

表示位置は、すべての移動に共通する規則に従って動きます。拡大・縮小のレベルは変わらず、キャンバスがスクロールするのは移動先がまだ十分に見えていない場合だけです。[移動先の表示位置](./table-related-functions.md#where-a-jump-lands)を参照してください。  
行へ移動すると、テーブルのプロパティが開いている場合はまずそれを閉じます。作成中のリレーションシップが始まったり確定したりすることはありません。  
検索フィールドにテキストがある間は、名前自体に一致箇所を含む行や、コメントやメモの抜粋を表示する行は、代わりにその一致箇所へ移動します。[一致箇所への移動](./find-and-replace.md#going-to-a-match)を参照してください。

クリックした後もキーボード操作はツリーに残るため、`Escape` を押すかキャンバスをクリックするまで、`Delete`、`Backspace` などの編集のキーは新しい選択に届きません。[エクスプローラー内のキー](#keys-in-the-explorer)を参照してください。

## エクスプローラー内のキー {#keys-in-the-explorer}

ツリーは全体で `Tab` の移動先 1 つになり、行がない間は飛ばされます。  
`Tab` でツリーに入ると、キーボードが最後にあった行に移り、その行がない場合は現在の一致箇所の行に、それもない場合は全体が見えている最初の行に移って、その行が見える位置までスクロールします。キーボードの行は、ポインタを重ねた行と同じように描画されます。

ツリーの中では、次のように動作します。

- `↑` と `↓` で 1 行ずつ移動し、折り返さずに最初と最後の行で止まります。`Home` と `End` で最初と最後の行へ移動します。
- `→` は折りたたまれた行を展開するか、展開された行の最初の子に移動します。`←` は展開された行を折りたたむか、その親に移動します。右から左に書く表示言語では、2 つのキーの役割が入れ替わります。
- `Enter` と `Space` はクリックと同じように動作し、その行へ移動するか、フォルダを折りたたむか展開します。[行への移動](#going-to-a-row)を参照してください。
- 文字を入力しても、その文字の行へ移動することはありません。

ツリー、検索フィールドや置換フィールド、ボタンの上など、エクスプローラー内のどこで `Escape` を押しても、キーボード操作はキャンバスに戻ります。エクスプローラーは開いたままで、選択もそのまま残ります。  
IME の変換を終える `Escape` は、変換を終えるだけです。エクスプローラー内で押しても、キャンバスで押しても、`Escape` でエクスプローラーが閉じることはありません。

キーボード操作がエクスプローラー内にある間も、いくつかのエディタのショートカットは動作します。[ショートカット](./settings.md#ショートカット)を参照してください。

- `Ctrl + F` (Windows/Linux) または `⌘ + F` (Mac) は、キャンバスで押したときと同じように動作します。エクスプローラーを閉じるか、横でテーブルのプロパティが開いている間は、テーブルのプロパティを閉じて検索フィールドにキャレットを置きます。[開き方と閉じ方](#opening-and-closing)を参照してください。
- `Ctrl + K` (Windows/Linux) または `⌘ + K` (Mac) はクイック検索を開閉します。
- `Undo` と `Redo` は、フィールドのテキストではなくダイアグラムを Undo、Redo します。
- `Zoom In`、`Zoom Out`、`Zoom Reset` はキャンバスを拡大・縮小します。

それ以外のエディタのショートカットはエクスプローラーの中にとどまり、矢印キー、`Tab`、`Enter`、`Space`、`Home`、`End`、IME の変換中に押したキーも同様です。  
どれもキャンバスには届きません。`Delete` と `Backspace` で選択しているものが削除されることはなく、`Alt + N` (Windows/Linux) または `⌥ + N` (Mac) でテーブルが追加されることも、`T` に続けて `G` で何かがグループにまとめられることもありません。フィールドの中では通常のテキストのキーとして動作し、`Ctrl + A` (Windows/Linux) または `⌘ + A` (Mac) はフィールドのテキストを選択し、`Delete` と `Backspace` はテキストを消去し、`Space` は空白を入力します。`Tab` は、エクスプローラーのボタン、フィールド、ツリーの間を移動します。  
検索フィールドと置換フィールド自体のキーについては、[検索と置換のフィールド内のキー](./find-and-replace.md#keys-in-the-search-fields)を参照してください。  
ホスト自身の保存やコマンドパレットのように、エディタが割り当てていないキーは、通常どおりホストに届きます。

## エクスプローラーの横のダイアログ {#dialogs-beside-it}

[テーブルのプロパティ](./table-related-functions.md#table-properties)、[テーマビルダー](./language-and-theme.md#テーマ)、[`Display Language`](./language-and-theme.md#言語の選択) のピッカー、[`Export image`](./file-import-export.md#画像) ダイアログ、[Map Columns](./relationship-editing.md#map-columns) は、開いてもエクスプローラーを開いたままにします。

- テーブルのプロパティは、エクスプローラーの横のキャンバスの中央に開き、キャンバスだけを暗くします。エクスプローラーは引き続き使え、行を選ぶとテーブルのプロパティが閉じてから、その行へ移動します。
- `Export image` と Map Columns は、ツールバーとエクスプローラーを含むエディタ全体を暗くします。エクスプローラーは暗くなった領域の下で開いたままで、暗くなった領域のほかの場所と同じように、そこをクリックするとダイアログが閉じます。このとき Map Columns は何も対応付けずに閉じます。
- 左から右に書く表示言語では、テーマビルダーと `Display Language` のピッカーはエクスプローラーに重ならず、そのすぐ横に開き、表示中にエクスプローラーが開閉するとそれに合わせて移動します。右から左に書く言語では、右側の位置のままです。ツールバー以外でそれらの外側を押したときと同じように、エクスプローラー内を押してもそれらは閉じます。

ショートカットか `Toggle Explorer` の項目で検索を開くと、5 つすべてが閉じ、Map Columns は何も対応付けずに閉じます。  
[クイック検索](./quick-search.md)もエクスプローラーを開いたままにし、このとき `Escape` はパレットだけを閉じます。

## 読み取り専用のエディタ {#read-only-editors}

[`readonly`](../../api/erd-editor-element.md#readonly) のエディタでも、エクスプローラーはほかのエディタと同じように動作します。同じツールチップのツールバーのボタン、ショートカット、両方の `Toggle Explorer` の項目、ツリー、折りたたみ、`Collapse All`、行への移動がすべて使え、行へ移動すると通常どおり移動先が選択されます。タイトルも同じく `Explorer` と表示されます。  
検索と置換は検索だけを行います。検索と置換の[読み取り専用のエディタ](./find-and-replace.md#read-only-editors)を参照してください。
