# テーブルの編集

テーブルの編集は、基本的に Excel に近い操作感で行えます。  
編集モードは `Enter`、またはセルのダブルクリックで開始します。  
`Enter` または `Escape` で終了します。入力した内容は入力と同時に反映されるため、`Escape` でもテキストは元に戻らず、そのまま残ります。  
`Escape` の後もセルはフォーカスされたまま、テーブルは選択されたままで、もう一度 `Escape` を押すと両方とも解除されます。  
IME の変換中は、`Escape` を押しても編集モードは終了しません。

![Alt + N でテーブルを追加し、2 つのカラムを入力](/img/demo-table-edit.webp)

## カラムの追加

ショートカット `Alt + Enter` (Windows/Linux) または `⌥ + Enter` (Mac) で作成します。  
選択しているすべてのテーブルにカラムが追加されます。

## Tab キー

`Tab` を押すと、次のセルの編集モードにそのまま移動します。  
最後のセルで `Tab` を押すと、新しいカラムを作成します。  
`Shift + Tab` で前のセルの編集モードに移動します。  
行の最後のセルの後ろに描画される[代替キー](./table-related-functions.md#alternate-keys)のマークはセルではないため、キーボードのフォーカスはマークを飛ばし、編集モードになることもありません。

![Tab でセルを移動し、最後のセルでカラムを追加して Shift + Tab で戻る](/img/demo-table-tab.webp)

## DataType の自動補完

`DataType` セルの編集を開始して入力すると、選択しているデータベースの型のうち、入力に一致するものが候補として表示され、入力した文字列をそのまま含む部分がハイライトされます。  
一致はあいまい検索のため、`vch` でも `VARCHAR` が見つかります。

- `Arrow Up` または `Arrow Down`: 候補を移動します。
- `Arrow Right`、`Tab` または `Enter`: ハイライトされている候補を確定します。
- `Arrow Left`: 入力した文字列に戻ります。

候補はクリックでも選択できます。  
一覧には一度に最大 10 件の候補が表示され、残りはスクロールで表示できます。  
入力は強制されないため、一覧にない型も自由に入力でき、`VARCHAR(255)` のような引数も指定できます。`VARCHAR(255)` や `BIGINT UNSIGNED` のように、入力が型名全体を超えると一覧は閉じます。  
候補は選択しているデータベースに従います。データベースを変更すると提示される候補が変わり、既存のカラムはそのまま残ります。

![矢印キー、Tab、Enter であいまい検索の候補から DataType を入力](/img/demo-data-type-autocomplete.webp)

## Not Null, Unique, Auto Increment

この 3 つのセルはテキストではなくトグルです。  
ダブルクリック、またはフォーカスした状態で `Enter` を押すと切り替わります。

Not Null のセルは、設定されているときは `N-N`、設定されていないときは `NULL` と表示されます。  
`UQ` と `AI` は、オフのときは薄く表示され、オンのときはハイライトされます。

![Not Null はダブルクリック、Unique と Auto Increment は Enter で切り替え](/img/demo-column-options.webp)

[テーブルの表示オプション](./table-related-functions.md)で非表示になっているセルは切り替えられません。

## カラムの複数選択

次の 5 つの方法に対応しています。

- `Shift + Arrow Up/Down`: 1 行ずつ選択範囲を広げます。
- `Ctrl + click` (Windows/Linux) または `⌘ + click` (Mac): カラムを 1 つ追加します。
- `Shift + click`: 最後にフォーカスしたカラムからの範囲を選択します。
- `Ctrl + Shift + click` (Windows/Linux) または `⌘ + Shift + click` (Mac): その範囲を選択に追加します。
- `Alt + A` (Windows/Linux) または `⌥ + A` (Mac): すべて選択

![Shift + Arrow Down、Ctrl/⌘ + click、Shift + click、Alt + A でカラムを選択](/img/demo-column-select.webp)

テーブルのコンテキストメニューの対象になるカラムは、どの修飾キーを押していても、カラムの行を右クリックした時点で決まります。  
すでに選択している行では、選択はそのままで、フォーカスがその行に移動します。それ以外の行では、その行だけが選択されます。これは、キーのアイコンや[代替キー](./table-related-functions.md#alternate-keys)のマークを含め、行のどこを右クリックしても同じです。  
そのため、[カラムの主キー](#カラムの主キー)や[カラムの削除](#カラムの削除)のようにメニューから複数のカラムを操作するには、選択している行のいずれかを右クリックします。  
Mac では `Ctrl + click` でもメニューが開きますが、通常のクリックとして扱われるため、セル上ではメニューが開く前にその行だけが選択されます。

## カラムの並べ替えと移動

`dragging` で動作し、他のテーブルへ移動できます。  
ドラッグした行はポインタに追従し、ドロップ位置の周りの行はずれて場所を空けます。  
テーブルの最後の行のすぐ下にドロップすると、カラムはそのテーブルの末尾に移動します。カラムのないテーブルでは、テーブル上のどこにドロップしても受け付けます。

![カラムをドラッグして並べ替え、別のテーブルへ移動](/img/demo-column-move.webp)

`Ctrl + drag` (Windows/Linux) または `⌘ + drag` (Mac) で複数カラムの移動にも対応しています。

![3 つのカラムを選択し、Ctrl/⌘ + drag で別のテーブルへ移動](/img/demo-column-multi-move.webp)

## カラムの削除

フォーカスしているテーブルの、選択しているカラムを削除します。セルをクリックするとそのカラムが選択されるため、セルをクリックして `Delete` を押すと、そのカラム 1 つが削除されます。  
ショートカット:

- `Delete` または `Backspace`（Mac では `⌫`）。そのカラムのテーブルだけを選択している間は、選択しているカラムを削除します。カラムを選択していない場合（フォーカスがテーブル名またはコメントにある場合）、ほかのものも一緒に選択している場合、またはテーブルが名前だけの表示になる `70%` 以下の拡大・縮小のレベルでは、代わりに選択全体を削除します。[テーブルとメモの削除](./table-related-functions.md#テーブルとメモの削除)を参照してください。
- `Alt + Backspace` または `Alt + Delete` (Windows/Linux)、`⌥ + ⌫` または `⌥ + Delete` (Mac)。ほかのテーブルやメモも一緒に選択している間でも、フォーカスしているテーブルの選択しているカラムを削除します。セルの編集中や `70%` 以下では、何も削除しません。

![Alt + Backspace でカラムを 1 つ、続けて選択した 2 つのカラムを削除](/img/demo-column-remove.webp)

テーブルのコンテキストメニューでも同じ操作ができます。そのテーブルだけを選択した状態でカラムの行を右クリックすると、メニューの最後の項目が `Delete column` と表示されます。その行が、選択している 2 つ以上のカラムの 1 つである場合は `Delete columns` と表示されます。

セルの編集中は、`Delete` と `Backspace` はテキストを消すだけです。セルの編集中でなければ、押し続けても削除は 1 回だけです。  
削除後、フォーカスは、フォーカスしていたカラムより上に残っている最も近いカラムに移動します。上にカラムが残っていない場合は、下にカラムが残っていてもフォーカスがテーブル名に移動するため、次の `Delete` または `Backspace` はカラムではなくテーブルを削除します。  
削除したカラムを使っているリレーションシップとインデックスも一緒に削除されます。確認はなく、削除全体が Undo の 1 ステップになります。

## カラムのコピー / 貼り付け

表形式のクリップボードとして動作します。  
ショートカット: `Ctrl + C` (Windows/Linux) または `⌘ + C` (Mac)、`Ctrl + V` (Windows/Linux) または `⌘ + V` (Mac)

スプレッドシートへのコピー、スプレッドシートからの貼り付け、カラムのセルにフォーカスしているテーブルへの貼り付けには、テーブルに表示されているセルが表示されている順序で使われます。[テーブルの表示オプション](./table-related-functions.md#table-view-options)と[カラム順の調整](./settings.md#adjusting-column-order)を参照してください。  
エディタでコピーしたカラムを、テーブルのヘッダーを選択した状態で貼り付けるか、選択しているほかのテーブルに貼り付けると、Unique や Auto Increment のような非表示のセルも含め、コピーしたカラムのすべてのセルが引き継がれます。  
`AK1.1` のような[代替キー](./table-related-functions.md#alternate-keys)のマークはセルではないため、表示されている場合でもコピーと貼り付けには含まれません。

エディタから Excel へ、Excel からエディタへ貼り付けられます。  
セルの値は入力したとおりに出力されるため、`<label>` や `a &amp; b` のような値も、そのままスプレッドシートやドキュメントに届きます。  
スプレッドシートの列は、名前ではなく位置で表示されているセルに対応するため、シートの列はそのセルの順序に従う必要があります。  
次のカラムでは、以下の値を true として扱います（大文字小文字は区別しません）。

- AutoIncrement: `TRUE`, `1`, `YES`, `Y`
- Unique: `TRUE`, `1`, `YES`, `Y`
- Not Null: `TRUE`, `1`, `YES`, `Y`, `NOT NULL`

書き出すときは、AutoIncrement と Unique は `TRUE` または `FALSE`、Not Null は `NOT NULL` または `NULL` として出力します。  
Unique と Auto Increment は既定で非表示のため、これらのセルを表示したときにだけ `TRUE` と `FALSE` を出力し、読み取ります。

![4 つのカラムをスプレッドシートに貼り付け、フラグは TRUE/FALSE と NOT NULL/NULL で出力](/img/demo-copy-column-to-sheet.webp)

![スプレッドシートの 3 行をカラムとしてテーブルに貼り付け、YES、1、NOT NULL は true として扱う](/img/demo-copy-sheet-column.webp)

貼り付け先は、フォーカスの位置によって変わります。

- テーブルのヘッダーを選択している場合は、貼り付けた行が、選択しているすべてのテーブルに新しいカラムとして追加されます。
- カラムのセルにフォーカスしている場合、そのテーブルでは、選択している行と、最後に選択した行より下の行が、貼り付けた行の数だけ順に上書きされます。離れた選択の間にある行は飛ばされます。上書きされた行は表示されているセルに貼り付けた値を受け取り、非表示のセルはそのまま残ります。余った行は新しいカラムとして追加されます。選択しているほかのテーブルには、貼り付けた行が新しいカラムとして追加されます。

![2 つのカラムをコピーし、選択した 2 つのテーブルにまとめて貼り付け](/img/demo-copy-column-multi.webp)

## テーブルとメモのコピー / 貼り付け

フォーカスしているテーブル内でカラムを選択していない場合は、同じショートカットで選択中のテーブルとメモ自体をコピーします。[テーブル関連機能](./table-related-functions.md)を参照してください。

## カラムの主キー

フォーカスしているカラムの主キーを切り替えます。対象はフォーカスしているセルが属するカラムです。  
フォーカスしているカラムが、選択している 2 つ以上のカラムの 1 つである場合は、選択しているすべてのカラムが切り替わります。そのうち 1 つでも主キーでないものがあればすべてが主キーになり、すべてがすでに主キーであればすべて解除されます。選択の外にあるカラムは変わりません。  
テーブルのコンテキストメニュー、またはショートカット `Alt + K` (Windows/Linux) または `⌥ + K` (Mac) で操作します。切り替えの対象が 2 つ以上のカラムになる場合、メニューの項目は `Primary Key` ではなく `Primary Key on selected columns` と表示されます。  
行に表示されるキーのアイコンは表示専用のため、クリックしても主キーは設定されません。

複数のカラムを 1 つの複合キーにするには、[カラムを選択](#カラムの複数選択)してから `Alt + K` (Windows/Linux) または `⌥ + K` (Mac) を押すか、選択している行のいずれかを右クリックして `Primary Key on selected columns` を選びます。切り替えは 1 回ごとに Undo の 1 ステップです。

![Shift + Arrow Down で 2 つのカラムを選択し、⌥ + K で両方を主キーにして、もう一度押して両方とも解除](/img/demo-column-pk.webp)
