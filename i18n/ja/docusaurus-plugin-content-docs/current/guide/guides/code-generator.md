# コード生成

ツールバーの `Code Generator` タブに切り替え、コード領域で右クリックしてコンテキストメニューを開きます。  
次の言語に対応しています。

- GraphQL
- C#
- Java
- Kotlin
- TypeScript
- JPA
- Scala

同じコンテキストメニューには `Table Name Case` と `Column Name Case` もあり、それぞれ `Pascal`、`Camel`、`Snake`、`None` に対応しています。
