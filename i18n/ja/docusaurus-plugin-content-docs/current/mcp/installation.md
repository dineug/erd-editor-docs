# インストール

サーバーは npm に `@dineug/erd-editor-mcp` として公開されています。
ランタイム依存のない自己完結した 1 つのファイルで、エージェントが初めて起動するときに `npx` がダウンロードするため、ほかにインストールするものはありません。
Node.js `22.12` 以降が必要です。

## Claude Code

プロジェクトのフォルダで実行します。

```sh
claude mcp add --transport stdio erd-editor -- npx -y @dineug/erd-editor-mcp
```

`--transport` の前に `--scope project` を加えると、代わりにプロジェクトの `.mcp.json` にサーバーが書き込まれ、プロジェクトをクローンした全員がそれを使えるようになります。

## Codex

`~/.codex/config.toml`、または信頼済みのプロジェクトの `.codex/config.toml` に追加します。

```toml
[mcp_servers.erd-editor]
command = "npx"
args = ["-y", "@dineug/erd-editor-mcp"]
```

## その他の MCP クライアント

`npx -y @dineug/erd-editor-mcp` を stdio サーバーとして実行します。コマンドは `npx`、引数は `-y` と `@dineug/erd-editor-mcp` です。

サーバーはドキュメントの相対パスを作業ディレクトリを基準に解決するため、プロジェクトのフォルダで起動してください。
MCP プロトコルのバージョン `2025-06-18`、`2025-03-26`、`2024-11-05` に対応し、それより新しいバージョンのクライアントには `2025-06-18` で応答します。

## VS Code の設定

エージェントがダイアグラムをライブで編集できるのは、VS Code 拡張機能を通じた場合だけです。拡張機能がない場合や、ドキュメントのフォルダを開いているウィンドウがない場合は、ディスク上のファイルを編集します。[ライブとヘッドレス](./live-and-headless.md)を参照してください。

1. [ERD Editor 拡張機能](https://marketplace.visualstudio.com/items?itemName=dineug.vuerd-vscode) `3.0.0` 以降をインストールします。VS Code `1.101.0` 以降が必要です。
2. プロジェクトのフォルダを開き、ワークスペースを信頼します。拡張機能がエージェントに応えるのは、信頼済みのワークスペースだけです。
3. `dineug.erd-editor.agentHub.enabled` 設定はオンのままにします。既定でオンです。

拡張機能は `.erd`、`.erd.json`、`.vuerd`、`.vuerd.json` ファイルを含むワークスペースで起動するため、ユーザーがダイアグラムを開く前から、エージェントはそれらのダイアグラムを扱えます。
どれも含まないワークスペースでは、ダイアグラムを開いたときに起動し、それまではエージェントはディスク上で編集します。

| 設定 | 既定値 | 効果 |
| --- | --- | --- |
| `dineug.erd-editor.agentHub.enabled` | `true` | エージェントの MCP サーバーが、ローカルのパイプを通じてこのウィンドウのドキュメントを編集できるようにします。オフにした場合や信頼されていないワークスペースでは、エージェントはこのウィンドウのダイアグラムをディスクから読み取ることはできますが、エディタの裏でファイルに書き込むことは決してありません。 |

## 試してみる

1. VS Code でプロジェクトのフォルダを開き、ワークスペースを信頼します。
2. 同じフォルダでエージェントを起動し、普段の言葉で頼みます。例えば _「schema.erd.json に reviews テーブルを追加して、users と products に関連付けて」_ のように頼みます。
3. 変更がキャンバスに反映されるのを確認してから、`Ctrl + S` (Windows/Linux) または `⌘ + S` (Mac) で保存するか、エージェントに保存を頼みます。

まだ開かれていないダイアグラムは、エージェントが最初に編集したときに ERD Editor で開きます。
エージェントは `erd_open_document` で新しいドキュメントを作成し、拡張子のない名前には `.erd.json` が付きます。

## アップデート

上記のコマンドはバージョンを指定していないため、エージェントがサーバーを起動するたびに、`npx` が npm でサーバーの新しいリリースを確認します。

サーバーは接続する前に、拡張機能が使うプロトコルのバージョンを確認します。
両者が異なると呼び出しは `protocolMismatch` で拒否され、更新が必要な側を示すメッセージが返ります。VS Code の ERD Editor 拡張機能か、サーバーのどちらかです。
