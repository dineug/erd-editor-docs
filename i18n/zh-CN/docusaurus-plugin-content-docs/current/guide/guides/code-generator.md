# 代码生成

切换到工具栏的 `Code Generator` 标签页，然后在代码区域右键打开菜单。  
支持以下语言：

- GraphQL
- C#
- Java
- Kotlin
- TypeScript
- JPA
- Scala

同一右键菜单还提供 `Table Name Case` 与 `Column Name Case`，均支持 `Pascal`、`Camel`、`Snake` 和 `None`。
