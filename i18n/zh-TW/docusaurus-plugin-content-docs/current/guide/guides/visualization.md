# 視覺化

以兩種模式之一，讓整份文件一目了然：

- `Graph`，由每個資料表、其欄位以及它們之間的關聯所構成的力導向圖，請參閱[關係圖模式](#graph-mode)。
- `Flow`，每個資料表都繪製為一張卡片，並沿著其關聯配置，請參閱[流程模式](#flow-mode)。

從頂端工具列的 `Visualization` 索引標籤開啟，或從[快速搜尋](./quick-search.md)的 `Tab` 中開啟。  
在 ERD 索引標籤上，`Alt + F` (Windows/Linux) 或 `⌥ + F` (Mac) 以及資料表右鍵選單中的 `Focus on this table` 項目會直接以 `Flow` 模式開啟它，並將範圍縮小到所選的資料表以及與其相隔一個關聯的資料表，請參閱[聚焦資料表](#focusing-on-tables)。

以[工具列](#toolbar)左端的 `Graph` 和 `Flow` 按鈕切換模式。  
新開啟的編輯器會從 `Graph` 開始。所選的模式在編輯器開啟期間會一直保留，前往其他索引標籤再回來也不會改變，但不會儲存在文件中。

## 工具列 {#toolbar}

工具列浮動在索引標籤底部邊緣的中央。由左至右依序為：

- `Graph` 和 `Flow`，目前的模式會醒目顯示。
- `Previous table` 和 `Next table`，僅在 `Flow` 中出現：向左箭頭和向右箭頭，會在流程模式曾縮小到的資料表之間返回上一步和前進到下一步，請參閱[上一個資料表與下一個資料表](#previous-table-and-next-table)。沒有可往該方向移動的步驟時，各按鈕會淡化顯示。
- `Zoom out`、以百分比表示的目前縮放比例（例如 `100%`）和 `Zoom in`。每按一次會讓縮放比例變動 4 個百分點，並讓畫面中央保持不動。百分比顯示的是目前所在模式的縮放比例，按一下即可將該縮放比例恢復為 `100%`。
- `Fit`，會將該模式顯示的所有內容都納入可見範圍內：在 `Graph` 中是所有節點，在 `Flow` 中是所有卡片。
- `Tidy Up`，僅在 `Flow` 中出現，會重新配置卡片，請參閱[流程模式的排列方式](#how-flow-is-placed)。
- 列顯示選單，僅在 `Flow` 中出現，以目前的選項作為標籤，請參閱[列顯示](#row-display)。
- `Name View` 清單，僅在 `Flow` 中出現，以目前的顯示方式作為標籤，請參閱[卡片上的名稱](#names-on-the-cards)。
- `Show all`，僅在 `Flow` 中且僅在檢視已縮小範圍時出現，會回到完整的圖表，請參閱[聚焦資料表](#focusing-on-tables)。
- `Go to content` 指南針，只有在畫面上沒有任何節點或卡片時才會加入工具列的末端。它會顯示指向最近節點或卡片的箭頭，以及其距離，例如 `1.2k`。按一下即可在不變更縮放比例的情況下，將該節點或卡片置中。

縮放按鈕和兩個箭頭會在工具提示中標示其快速鍵，例如 `Zoom in (Ctrl + Plus)` (Windows/Linux) 或 `Zoom in (⌘ + Plus)` (Mac)，以及 `Previous table (Ctrl + Z)` (Windows/Linux) 或 `Previous table (⌘ + Z)` (Mac)。  
在任一模式中，`Ctrl + Plus` 和 `Ctrl + Minus` (Windows/Linux) 或 `⌘ + Plus` 和 `⌘ + Minus` (Mac) 都會像按鈕一樣逐步縮放，而 `Ctrl + 0` (Windows/Linux) 或 `⌘ + 0` (Mac) 會直接回到 `100%`。在 `Flow` 中，`Ctrl + Z` 和 `Ctrl + Shift + Z` (Windows/Linux) 或 `⌘ + Z` 和 `⌘ + Shift + Z` (Mac) 會像兩個箭頭一樣逐步移動。  
按一下百分比的作用與 `Ctrl + 0` (Windows/Linux) 或 `⌘ + 0` (Mac) 相同，其工具提示中也會標示此快速鍵。快速搜尋開啟時，這些快速鍵不會有任何作用。

## 關係圖模式 {#graph-mode}

將整份文件繪製為力導向圖，讓資料表之間如何相互關聯，以及哪些資料表位於某個領域的中心，都能一目了然。

![開啟關係圖模式、將指標停留在資料表上以顯示其預覽、拖曳節點，再縮小並放大回來](/img/demo-visualization.webp)

### 解讀關係圖 {#reading-the-graph}

每個資料表和每個欄位都是一個節點，這兩種節點會以不同的顏色繪製。備忘錄和[資料表群組](./table-groups.md)不會繪製出來。  
每個欄位節點都會連結到其所屬的資料表，以關聯連接的兩個資料表也會彼此連結。  
以多個同方向的關聯連接的資料表只會連結一次，而起點與終點位於同一個資料表的關聯不會繪製連結。

放大時，資料表名稱會出現在關係圖上，在 `50%` 到 `100%` 之間逐漸淡入，超過 15 個字元的名稱會被截斷。欄位節點在任何縮放比例下都沒有標籤。  
這些標籤會依循「名稱顯示」，請參閱[畫布以外的地方](./logical-names.md#beyond-the-canvas)。在 `Both Names` 中，標籤會將邏輯名稱放在一行，並將名稱放在其下一行，且每一行都會各自截斷。

### 瀏覽關係圖 {#getting-around-the-graph}

滾輪會以指標所在的位置為中心縮放，範圍從 `10%` 到 `400%`。  
觸控板上的雙指縮放也以相同方式縮放，而觸控螢幕上的兩根手指會以兩指之間的點為中心縮放，並隨著移動而平移。  
拖曳背景即可平移，也可以從任何位置（包括節點上）以滑鼠中鍵拖曳，與在 [ERD 畫布](./table-related-functions.md#getting-around-the-canvas)上相同。以中鍵拖曳只會平移：永遠不會拉動節點。

[工具列](#toolbar)上的縮放按鈕和縮放快速鍵則改為讓畫面中央保持不動，範圍相同，而 `Fit` 會將所有節點都納入可見範圍內。

### 懸停預覽 {#hover-preview}

將指標停留在資料表節點上，即可在游標旁預覽該資料表。  
將指標停留在欄位節點上只會在其周圍繪製一個圓環；不會開啟任何預覽。

預覽顯示的欄位和儲存格與 ERD 畫布相同，順序也相同，並依您目前的「名稱顯示」，以與畫布相同的方式顯示其名稱，請參閱[資料表檢視選項](./table-related-functions.md#table-view-options)、[調整欄位順序](./settings.md#adjusting-column-order)和[名稱顯示](./logical-names.md#name-view)。  
開啟 `Alternate Key` 檢視選項時，[替代鍵](./table-related-functions.md#alternate-keys)的每個欄位都會在其列的最後帶有標記，例如 `AK1.1`，預覽也會像 ERD 畫布上的資料表一樣為此加寬。  
與 ERD 畫布上的資料表不同，預覽的表頭永遠不會呈現資料表所屬[群組](./table-groups.md#coloring-a-group)的顏色，其名稱也永遠不會帶有字典的檢查在畫布上加上的[標示](./dictionary.md#marks-on-the-canvas)。  
預覽僅供顯示，在拖曳節點或平移時會隱藏。

### 醒目顯示相鄰範圍 {#highlighting-a-neighbourhood}

將指標停留在資料表上也會亮起其相鄰範圍：資料表本身、其自身的欄位、其關聯在任一方向上連接的資料表，以及它們之間的連結。  
關係圖上的其他所有內容都會淡出，讓該資料表所觸及的範圍能單獨辨識。

### 移動節點 {#moving-nodes}

以滑鼠左鍵拖曳節點，即可將它連同與它連結的所有內容拉到新的位置。  
按住期間，節點會固定在指標下方，其周圍的版面配置也會重新活躍起來。  
放開後會再次穩定下來：沒有任何節點會固定在放開的位置。  
在節點上按下右鍵或以右鍵拖曳，既不會拉動節點，也不會平移。

### 關係圖是快照 {#the-graph-is-a-snapshot}

關係圖是根據開啟此索引標籤當下的文件建立的，每次回到這裡時都會從頭重新建立。  
從 `Flow` 切換到 `Graph` 也會重新建立關係圖，且每次重新建立都會從 `100%` 開始。

## 流程模式 {#flow-mode}

將每個資料表繪製為一張卡片，並沿著其關聯配置這些卡片。備忘錄和[資料表群組](./table-groups.md)不會繪製出來。  
這並不是[自動版面配置](./table-related-functions.md#auto-layout)的 `Flow` 版面配置，後者會移動 ERD 索引標籤上的資料表本身。

每張卡片的繪製方式都與 ERD 索引標籤上的資料表相同：左側邊緣是資料表的顏色，接著是帶有資料表圖示以及依[名稱顯示](#names-on-the-cards)所呈現之資料表名稱的表頭，然後是其[列顯示](#row-display)所要求的各列。與 ERD 索引標籤上的資料表不同，卡片還會在各列之間繪製分隔線，其表頭也永遠不會呈現資料表所屬[群組](./table-groups.md#coloring-a-group)的顏色。卡片在任何縮放比例下都保持這個外觀，永遠不會像 ERD 索引標籤上的資料表在 `70%` 及以下時那樣收合為只顯示名稱。卡片上的任何內容都無法編輯。

連接線是從資料表到資料表的一條平滑曲線，繪製在卡片下方，因此可能從卡片後方穿過。從資料表連到自身的關聯會繞過卡片的右上角，與 ERD 索引標籤上相同，請參閱[連接線路徑](./relationship-editing.md#connector-routing)。無論關聯是否為識別關聯，每條連接線都繪製為相同的灰色實線，兩端的標記也與 ERD 索引標籤上相同，請參閱[解讀連接線](./relationship-editing.md#reading-a-connector)。即使 `Relationship` [檢視選項](./table-related-functions.md#table-view-options)已關閉，流程模式仍會繪製連接線。無論 `Referential Actions` 檢視選項如何設定，流程模式都不會繪製關聯的 ON DELETE 與 ON UPDATE 動作的 `D:` 和 `U:` 標籤，也不會顯示完整寫出這些動作的工具提示。

在完整的圖表中，未透過任何關聯與其他資料表連接的資料表會集中在一個區塊中，而不會散布在其他資料表之間。

![切換到流程模式、將指標停留在 orders 上使其與相鄰的資料表亮起、固定亮顯、選擇 Keys only，然後以 ⌘ + Wheel 放大並按下 Fit](/img/demo-visualization-flow.webp)

### 列顯示 {#row-display}

[工具列](#toolbar)上的列顯示選單決定每張卡片要繪製多少內容。其標籤是目前的選項，工具提示則例如顯示為 `Row display: Name only`。  
選單會在工具列上方開啟，目前的選項旁有勾號。選擇一個選項、再次按一下標籤、按一下編輯器中的其他任何位置、按 `Escape` 或切換到 `Graph` 時，選單都會關閉。

| 列顯示 | 每張卡片顯示的內容 |
| --- | --- |
| `Name only` | 只有表頭。 |
| `Keys only` | 主鍵欄位和外鍵欄位，以及作為關聯端點的其他任何欄位。 |
| `All fields` | 所有欄位。 |

各列依資料表的欄位順序排列。每一列都會顯示欄位名稱，當該欄位是主鍵、外鍵或兩者皆是時，名稱前會有鑰匙圖示；右側則顯示資料類型，無論卡片是否[亮起](#lighting-related-tables)都會顯示。[名稱顯示](#names-on-the-cards)決定一列要顯示哪些名稱，以及是否顯示該欄位的定義域。  
不會繪製其他任何儲存格或替代鍵標記，[資料表檢視選項](./table-related-functions.md#table-view-options)和用於排列列內儲存格順序的[調整欄位順序](./settings.md#adjusting-column-order)也都不適用於卡片。

流程模式第一次開啟時，會從 `Name only` 開始；如果是透過[聚焦資料表](#focusing-on-tables)開啟的，則從 `Keys only` 開始。此後，只有在選擇其他選項時列顯示才會改變，縮小範圍或恢復完整範圍時都會保留。  
變更列顯示會改變卡片的大小，因此流程模式會重新配置卡片，並使其符合畫面大小。

### 卡片上的名稱 {#names-on-the-cards}

卡片會依「名稱顯示」顯示其資料表和欄位的名稱，與 ERD 索引標籤繪製時所依循的是同一個設定，請參閱[名稱顯示](./logical-names.md#name-view)。  
可在此使用[工具列](#toolbar)上的 `Name View` 清單切換。其按鈕會顯示目前的顯示方式（`Physical Names`、`Logical Names` 或 `Both Names`），工具提示則顯示 `Name View`。清單會在工具列上方開啟，目前的顯示方式旁有勾號，關閉方式與[列顯示](#row-display)選單相同。選擇一個顯示方式會切換整個編輯器（包括 ERD 索引標籤），與在其他任何地方所做的切換相同，請參閱[切換顯示方式](./logical-names.md#switching-the-view)。

卡片只依「名稱顯示」排列其儲存格。任何[檢視選項](./table-related-functions.md#table-view-options)都不會改變它們，包括 `Domain`：

| 名稱顯示 | 表頭 | 每一列 |
| --- | --- | --- |
| `Physical Names` | 資料表名稱。 | 欄位名稱，接著是資料類型。 |
| `Logical Names` | 資料表的邏輯名稱。 | 欄位的邏輯名稱，接著是其[定義域](./dictionary.md#domains-and-data-types)的名稱；沒有定義域時則為其資料類型。 |
| `Both Names` | 邏輯名稱，接著是以次要色彩顯示的資料表名稱。 | 邏輯名稱、名稱、定義域和資料類型。 |

邏輯名稱為空白時，`Logical Names` 會在其位置淡化顯示名稱，若名稱也是空白的，則顯示 `table` 或 `column` 預留位置文字，而 `Both Names` 會顯示淡化顯示的預留位置文字 `logical`。在 `Both Names` 中，沒有定義域的欄位會顯示淡化顯示的預留位置文字 `domain`。  
卡片永遠不會帶有字典的檢查在 ERD 索引標籤上為名稱加上的[標示](./dictionary.md#marks-on-the-canvas)。  
切換「名稱顯示」會改變卡片的大小，因此流程模式會重新配置卡片，請參閱[流程模式的排列方式](#how-flow-is-placed)。

### 瀏覽流程模式 {#getting-around-the-flow}

滾輪會平移，`Shift + Wheel` 則會左右平移。`Ctrl + Wheel` (Windows/Linux) 或 `⌘ + Wheel` (Mac) 會縮放，並讓畫面中央保持不動。  
觸控板上的雙指縮放會以雙指所在的位置為中心縮放，而觸控螢幕上的兩根手指會以兩指之間的點為中心縮放，並隨著移動而平移。  
拖曳背景即可平移，也可以從任何位置（包括卡片上）以滑鼠中鍵拖曳。以中鍵拖曳只會平移，並保持選取範圍不變。平移沒有邊界，與在 [ERD 畫布](./table-related-functions.md#getting-around-the-canvas)上相同。  
縮放範圍從 `10%` 到 `150%`。流程模式有獨立於 ERD 索引標籤的縮放與平移，兩者都不會儲存在文件中。

在背景上按下會清除選取範圍，而在背景上使用 `Ctrl + drag` (Windows/Linux) 或 `⌘ + drag` (Mac) 會繪製選取框。  
流程模式沒有小地圖，也沒有捲軸。平移後畫面上沒有任何卡片時，可使用[工具列](#toolbar)上的 `Go to content` 指南針。

### 亮起相關資料表 {#lighting-related-tables}

將指標停留在卡片上，即可亮起該卡片、與其相隔一個關聯的資料表，以及將其連接到這些資料表的連接線。這些資料表中任兩者之間的連接線不會亮起。  
亮起的卡片會有強調色的邊框和光暈，作為關聯端點的列也會加上色調。亮起的連接線會變成強調色。  
與[關係圖模式](#highlighting-a-neighbourhood)不同，其他內容都不會淡出；沒有卡片處於懸停或固定狀態時，則不會亮起任何內容。

按一下卡片即可固定其亮顯，讓指標移開後卡片仍保持亮起。再按一下同一張卡片或按一下背景即可解除固定；按一下另一張卡片則會將固定轉移到該卡片上。懸停的卡片和固定的卡片會同時亮起。  
拖曳、`Ctrl + click` (Windows/Linux) 或 `⌘ + click` (Mac)、平移以及[卡片按鈕](#card-buttons)都不會固定或解除固定卡片。

粒子會沿著每條亮起的連接線流動，從主鍵所在的父資料表一端流向子資料表一端。同時亮起的連接線超過 60 條時，粒子會停止，亮顯則會保留。

### 卡片按鈕 {#card-buttons}

指標位於卡片上時，其表頭右端會出現兩個圖示按鈕，兩者都沒有工具提示：

- 航點圖示（與 `Flow` 按鈕顯示的圖示相同）會將流程模式的範圍縮小到該資料表以及與其相隔一個關聯的資料表，請參閱[聚焦資料表](#focusing-on-tables)。流程模式先前顯示的內容會保留，按一次 `Previous table` 即可回到，請參閱[上一個資料表與下一個資料表](#previous-table-and-next-table)。
- 外部連結圖示會切換到 ERD 索引標籤、只選取該資料表、將其移到最前面，並將焦點儲存格移到其名稱上（在 `Logical Names` 和 `Both Names` 中則是其邏輯名稱上），除非該資料表的某個儲存格已是焦點儲存格。只有在資料表尚未清楚顯示時，畫布才會捲動到該資料表，請參閱[跳至目標時的落點](./table-related-functions.md#where-a-jump-lands)。它永遠不會開始或完成正在繪製的關聯。

在任一按鈕上按下都只作用於該按鈕本身：與在卡片其他位置按下不同，它不會選取卡片，也不會將其移到最前面。因此，航點按鈕會保留原本的選取範圍；外部連結按鈕只會在切換到 ERD 索引標籤的過程中選取該資料表。兩個按鈕都只能以滑鼠左鍵按一下來操作。

### 移動卡片 {#moving-cards}

以滑鼠左鍵拖曳卡片上除兩個卡片按鈕以外的任何部分，即可移動卡片；以右鍵拖曳不會移動任何內容。  
按下卡片會將其選取，`Ctrl + click` (Windows/Linux) 或 `⌘ + click` (Mac) 會將其加入選取範圍，拖曳已選取的卡片則會移動所有已選取的卡片。此選取範圍與 ERD 索引標籤所使用的相同，因此在這裡選取的項目，回到 ERD 索引標籤時仍會保持選取。

卡片只會在流程模式中移動：其資料表在 ERD 索引標籤上仍留在原處。  
移動過的卡片在平移、縮放和 `Fit` 之後都會保持原位。離開此索引標籤或切換到 `Graph` 再回來時，以及 `Show all` 或某個[步驟](#previous-table-and-next-table)回到流程模式已有的版面配置時，卡片會回到版面配置所排列的位置。新的版面配置會考量您放置卡片的位置，重新排列卡片，請參閱[流程模式的排列方式](#how-flow-is-placed)。

### 聚焦資料表 {#focusing-on-tables}

在 ERD 索引標籤上，選取一個或多個資料表後按 `Alt + F` (Windows/Linux) 或 `⌥ + F` (Mac)，或在資料表上按滑鼠右鍵並選擇 `Focus on this table`。  
「視覺化」索引標籤會以 `Flow` 模式開啟，並將範圍縮小到這些資料表，以及在任一方向上與其中任何一個相隔一個關聯的所有資料表。只會繪製所顯示資料表之間的連接線。

當按滑鼠右鍵的資料表是多個已選取資料表之一時，此項目會顯示 `Focus on selected tables`，並聚焦整個選取範圍。在選取範圍外的資料表上按滑鼠右鍵，只會聚焦該資料表。  
`Alt + F` 會採用所選的資料表，不包括備忘錄和[資料表群組](./table-groups.md)。未選取任何資料表時，即使選取了群組，它也不會有任何作用：先在群組的右鍵選單中選擇 `Select tables`，請參閱[選取群組](./table-groups.md#selecting-groups)。  
正在編輯儲存格、備忘錄或群組名稱時，鍵盤焦點位於[物件總管](./explorer.md#keys-in-the-explorer)中時，或者快速搜尋、「資料表屬性」、差異檢視器、自動版面配置預覽、時光旅行、[`Export image`](./file-import-export.md#image) 對話方塊或 [`Map Columns`](./relationship-editing.md#map-columns) 開啟時，它都會被忽略。

在流程模式中，航點[卡片按鈕](#card-buttons)會以相同方式將檢視縮小到該資料表。[工具列](#toolbar)上的 `Show all` 會回到完整的圖表。工具列上的 `Previous table` 和 `Next table` 或其按鍵，會在流程模式曾縮小到的範圍之間返回上一步和前進到下一步，請參閱[上一個資料表與下一個資料表](#previous-table-and-next-table)。  
縮小範圍的檢視會單獨配置，並符合畫面大小。離開此索引標籤或切換到 `Graph` 再回來時，檢視仍會保持縮小範圍，而 `Escape` 不會將其恢復完整範圍。

![以 ⌥ + F 聚焦 orders，再以 members 卡片的航點按鈕將範圍縮小到 members，然後按下 Show all](/img/demo-visualization-focus.webp)

### 上一個資料表與下一個資料表 {#previous-table-and-next-table}

流程模式會像瀏覽器的歷程記錄一樣，記住它曾縮小到的範圍。每當檢視移到其他資料表時（無論是從 ERD 索引標籤[聚焦資料表](#focusing-on-tables)、使用航點[卡片按鈕](#card-buttons)，還是使用 `Show all`），先前顯示的內容都會保留為上一步，無論那是少數幾個資料表還是完整的圖表。

![將流程模式以 ⌥ + F 縮小到 orders，再縮小到 members，然後以 Previous table 返回上一步、以 ⌘ + Shift + Z 前進、以 ⌘ + Z 返回，最後按下 Show all](/img/demo-visualization-steps.webp)

- [工具列](#toolbar)上的 `Previous table` 會返回上一步，而 `Next table` 會再前進到 `Previous table` 離開的內容。
- 在 `Flow` 中，`Ctrl + Z` (Windows/Linux) 或 `⌘ + Z` (Mac) 會像 `Previous table` 一樣返回上一步，而 `Ctrl + Shift + Z` (Windows/Linux) 或 `⌘ + Shift + Z` (Mac) 會像 `Next table` 一樣前進到下一步。它們在該處永遠不會復原或重做圖表的編輯。在 `Graph` 中以及快速搜尋開啟期間，它們不會有任何作用。
- 返回上一步之後縮小檢視範圍或按下 `Show all`，會捨棄往前的步驟。再次聚焦於流程模式目前所縮小到的完全相同的資料表，既不會新增步驟，也不會捨棄任何步驟。
- 最多保留最近 100 個返回步驟，最舊的會最先被捨棄。

步驟會顯示其資料表中仍存在於圖表中的資料表，以及與其相隔一個關聯的所有資料表，與聚焦時相同。資料表已全部被移除的步驟會被跳過並捨棄，會讓流程模式停留在原處的步驟也是如此：也就是正好是目前縮小到的那些資料表，或在流程模式已顯示完整圖表時的完整圖表。  
沒有可往該方向移動的步驟時，按鈕會淡化顯示，且不會有任何作用。流程模式第一次開啟時，無論是顯示完整的圖表，還是顯示透過聚焦開啟時的資料表，兩個按鈕都會淡化顯示。流程模式開啟之後，再從 ERD 索引標籤聚焦時，會將您離開時流程模式所顯示的內容保留為上一步。  
步驟會像聚焦一樣進行配置並符合畫面大小（請參閱[流程模式的排列方式](#how-flow-is-placed)），列顯示則維持不變。

這些步驟屬於流程模式本身。編輯器開啟期間會一直保留，前往其他索引標籤或 `Graph` 再回來也不會改變，但不會儲存在文件中，也不會傳送給協作者，且不會在復原歷程記錄中加入任何內容。取代整份文件時，這些步驟會與流程模式的其他內容一起被捨棄。

在由右至左的顯示語言中，工具列會保持其順序，兩個箭頭的作用則會互換，因此 `Previous table` 是指向右方的箭頭。按鍵維持不變，請參閱[由右至左書寫的語言](./language-and-theme.md#right-to-left-languages)。

### 流程模式的排列方式 {#how-flow-is-placed}

第一次顯示 `Flow` 時，其顯示的資料表會在主執行緒之外配置，結果會符合畫面大小。  
編輯器開啟期間會保留此版面配置。離開此索引標籤或切換到 `Graph` 再回來時，流程模式會重複使用它，縮放與平移也維持在離開時的狀態。  
流程模式會為完整的圖表和最後一次縮小到的資料表各保留一個版面配置，因此只要建立完整圖表版面配置所依據的內容都沒有變更，`Show all` 就會回到該版面配置並使其符合畫面大小，而不必重新計算。前往完整圖表或流程模式最後一次縮小到之資料表的[步驟](#previous-table-and-next-table)，也會以相同方式重複使用該版面配置。

流程模式會在下列情況重新配置卡片：

- 按下 `Tidy Up`。結果會符合畫面大小。
- 變更列顯示、將檢視範圍縮小到其他資料表，或使用 `Previous table` 或 `Next table` 移到其他資料表。結果會符合畫面大小。
- 在 `Name View` 清單中選擇其他顯示方式。結果會符合畫面大小。
- 新增或移除了資料表或關聯，或切換了「名稱顯示」：可能是在離開流程模式期間進行（回來時才會反映），也可能是您位於流程模式中時由協作者進行。縮放與平移會維持不變。

每次配置都會考量卡片目前的位置，因此 `Tidy Up` 不一定會恢復先前的排列。  
只改變卡片大小的變更（例如重新命名資料表、輸入邏輯名稱或新增欄位）不會重新配置卡片。如果卡片最後彼此重疊，請按 `Tidy Up`。

耗時超過 6 秒的配置會顯示 `Placing tables` 通知，並附有旋轉的載入圖示和 `Cancel`。  
`Cancel`，或在配置執行期間隨時按 `Escape`，都會捨棄此次配置；`Tidy Up` 或回到 `Flow` 則會再次要求配置。  
如果配置失敗（主應用程式未執行任何 shared worker、worker 無法啟動，或 60 秒內沒有傳回版面配置），流程模式會顯示帶有警告符號的 `Could not place tables` 通知，按 `Tidy Up` 即可重試。請參閱 [Web Worker](../../api/installation.md#web-workers)。  
無論是在完整的圖表中還是縮小範圍的檢視中，流程模式都只會繪製最近一次版面配置所排列的資料表，因此第一次顯示時，在配置成功之前可能完全沒有任何卡片。  
每當流程模式重新配置卡片時（例如將檢視範圍縮小到其他資料表時），先前的排列都會留在畫面上，直到新的版面配置完成為止；如果該配置被取消或失敗，先前的排列也會繼續留在畫面上。

整份文件被取代時（例如匯入檔案），流程模式的版面配置、聚焦、`Previous table` 和 `Next table` 的步驟、列顯示、縮放和平移都會被捨棄，下次開啟流程模式時，它會像第一次一樣重新開始：顯示完整的圖表，或者如果是透過[聚焦資料表](#focusing-on-tables)開啟的，則顯示縮小範圍的檢視。

### 流程模式從不編輯文件 {#flow-never-edits-the-document}

流程模式只會讀取圖表。縮放、平移、移動卡片、`Tidy Up`、列顯示、固定、聚焦，以及使用 `Previous table` 和 `Next table` 逐步移動，都不會在[復原歷程記錄](./undo-redo.md#what-the-history-records)中加入任何內容。  
這些操作也不會變更圖表中的任何內容。按下卡片確實會將其資料表移到最前面，就像在 ERD 索引標籤上按一下資料表一樣，因此該資料表在那裡也會位於最前面，但堆疊順序不會儲存，請參閱[移動多個資料表](./table-related-functions.md#moving-multiple-tables)。`Graph` 同樣不會變更圖表。  
`Name View` 清單是個例外，且僅限於 `Name View` [鎖定](./settings.md#lock)關閉期間：此時選擇會切換圖表的「名稱顯示」，此設定會被儲存，協作者也會隨之切換。鎖定開啟期間（預設即為開啟），選擇只會變更您自己的畫面。無論哪種情況，都不會在復原歷程記錄中加入任何內容。  
按下卡片永遠不會新增關聯。如果在繪製關聯時離開了 ERD 索引標籤，尚未選定起點資料表時，按下卡片會將其資料表選為起點，否則會結束繪製。  
外部連結[卡片按鈕](#card-buttons)則更進一步，因為它會讓您離開流程模式：當 ERD 索引標籤必須捲動到該資料表時，這次捲動會像其他任何檢視位置的變更一樣被記錄下來。

位於流程模式中時，協作者的編輯仍會反映到圖表上，卡片也會隨著他們新增或移除的資料表與關聯而變化，請參閱[流程模式的排列方式](#how-flow-is-placed)。  
他們的選取框線與焦點框線會繪製在卡片上，但他們的游標和拖曳框不會，請參閱[協作編輯](../../api/advanced/collaborative-editing.md)。

兩種模式（包括聚焦和逐步移動）在 `readonly` 編輯器中也都能使用，`Name View` 清單也是如此，但在該處只會切換您自己的畫面。
