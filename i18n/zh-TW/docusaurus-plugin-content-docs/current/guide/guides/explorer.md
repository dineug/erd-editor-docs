# 物件總管

物件總管是停駐在 ERD 畫布左側邊緣的面板，以樹狀結構列出圖表：先是資料表（每個資料表各含其欄位、索引和外鍵），接著是[資料表群組](./table-groups.md)，然後是備忘錄。按一下某列即可前往其在畫布上所代表的項目。  
物件總管會讓畫布變窄，而不是覆蓋畫布。它是圖表編輯器的一部分，而不是 VS Code 的 Explorer 檢視或 Obsidian 的檔案總管。

![從工具列開啟物件總管，前往 products，再前往 orders 的 status 欄位和 member_id 外鍵，以 Collapse All 摺疊，加寬面板，然後將其關閉](/img/demo-explorer.webp)

[尋找與取代](./find-and-replace.md)位於其頂端，在標題列與樹狀結構之間。「尋找」輸入框中有文字時，樹狀結構只會顯示相符的項目，請參閱[搜尋結果](./find-and-replace.md#the-results)。  
樹狀結構本身絕不會變更圖表：它不提供重新命名、拖曳、刪除，也不提供顯示與隱藏。取代是此面板唯一會進行的編輯。

物件總管本身的狀態只屬於您自己：是否開啟、寬度、摺疊狀態、鍵盤焦點所在的列、捲動位置，以及搜尋。  
這些狀態都不會儲存在檔案中、記錄在復原歷程記錄中、與協作者共用，也不會存放在瀏覽器中。只要編輯器保持開啟，這些狀態就會保留，無論是切換索引標籤，或在同一個編輯器中載入其他文件都是如此。新開啟的編輯器中，物件總管一開始為關閉狀態。

## 開啟與關閉 {#opening-and-closing}

可使用以下任一方式開啟：

- 工具列的 `Explorer` 按鈕，緊接在 `Search` 之後，帶有樹狀圖示。其工具提示為 `Explorer (Ctrl + F)` (Windows/Linux) 或 `Explorer (⌘ + F)` (Mac)。
- `Ctrl + F` (Windows/Linux) 或 `⌘ + F` (Mac)，在設定的「[快速鍵](./settings.md#shortcuts)」索引標籤中名為 `Toggle Explorer`。
- [快速搜尋](./quick-search.md)中的 `Toggle Explorer`，在每個索引標籤中都會列出。輸入 `find`、`replace`、`rename`、`tree`、`outline` 或 `objects` 即可找到它。
- 畫布的右鍵選單中的 `Toggle Explorer`：在 ERD 畫布上任何[資料表群組](./table-groups.md)以外的空白處按滑鼠右鍵。它位於 `New Table`、`New Memo` 和 `New Table Group` 之後、`Relationship` 之前。唯讀編輯器的畫布選單沒有這個項目，請參閱[唯讀編輯器](#read-only-editors)。

這兩個 `Toggle Explorer` 項目會在右側顯示快速鍵。  
工具列按鈕、快速鍵和快速搜尋中的項目在每個索引標籤中都有效。在「視覺化」、「結構描述 SQL」、「程式碼產生器」、「字典」或「設定」索引標籤中使用時，它們會先切換到 ERD 索引標籤，因為物件總管只會顯示在該處。

工具列按鈕只會開啟和關閉面板。它不會將插入點放入「尋找」輸入框，也會讓「資料表屬性」、佈景主題建立器和 `Display Language` 選擇器保持開啟。  
快速鍵和這兩個 `Toggle Explorer` 項目會開啟物件總管並定位到其搜尋：插入點會移到「尋找」輸入框並選取其中的文字，且[物件總管旁的對話方塊](#dialogs-beside-it)中的五個對話方塊無論哪一個開啟都會關閉。關於搜尋在兩次開啟之間會保留哪些內容，請參閱尋找與取代中的[開啟與關閉](./find-and-replace.md#opening-and-closing)。  
編輯資料表儲存格、備忘錄或資料表群組名稱期間，或[字典](./dictionary.md#keys-on-the-tab)索引標籤上有儲存格編輯開啟期間（包括術語的定義域清單），快速鍵不會有任何作用。

物件總管在 ERD 索引標籤中為開啟狀態，且未被[禪模式](#when-it-stands-aside)隱藏時，工具列按鈕會顯示為按下狀態。此時，此按鈕、快速鍵和任一個 `Toggle Explorer` 項目都會關閉物件總管，原本位於面板中的鍵盤焦點會回到編輯器。  
快速搜尋或五個對話方塊之一開啟期間，快速鍵絕不會關閉物件總管。它會改為關閉命令選擇區或該對話方塊，並將鍵盤焦點移到「尋找」輸入框，選取其中的文字；若物件總管原本已在顯示中，則會保留目前的相符項目。快速搜尋中的 `Toggle Explorer` 項目沒有這種例外：執行它會關閉命令選擇區，然後關閉已開啟的物件總管。

標題列中工具提示為 `Close` 的 `x` 按鈕也會關閉物件總管，並將鍵盤焦點交給畫布。`Escape` 不會關閉物件總管，請參閱[物件總管中的按鍵](#keys-in-the-explorer)。  
重新開啟時，物件總管會以相同的寬度恢復，樹狀結構的摺疊狀態和捲動位置維持原樣，搜尋字串也相同。以快速鍵或 `Toggle Explorer` 項目開啟時，它會以該搜尋字串再次搜尋，並展開所有結果，請參閱[搜尋結果](./find-and-replace.md#the-results)。

快速鍵或 `Toggle Explorer` 項目在窄到無法容納物件總管的編輯器中開啟物件總管時，會顯示 `Widen the window to show the Explorer` 快顯通知，鍵盤焦點則留在原處，請參閱[位於畫布旁](#beside-the-canvas)。  
儘管如此，物件總管仍為開啟狀態，工具列按鈕也顯示為按下狀態，一旦編輯器夠寬，物件總管就會以已完成搜尋的狀態出現，且不會取得鍵盤焦點。以工具列按鈕開啟時不會顯示快顯通知。

## 位於畫布旁 {#beside-the-canvas}

物件總管位於工具列下方，沿著 ERD 索引標籤的左側邊緣延伸，涵蓋畫布的整個高度。  
畫布會變窄以騰出空間，因此圖表的任何部分都不會位於面板下方，而[畫布工具列](./table-related-functions.md#canvas-toolbar)、小地圖和[歡迎畫面](./editing-start.md#welcome-screen)也都位於其旁邊的畫布中。  
開啟、關閉物件總管或調整其大小，都不會捲動圖表，也不會在[復原歷程記錄](./undo-redo.md#what-the-history-records)中記錄任何內容。

在新開啟的編輯器中，其初始寬度為 `260px`。拖曳其右側邊緣即可將寬度設為 `200px` 到 `480px` 之間的任何值，按兩下該邊緣則可恢復為 `260px`。

畫布一定會在物件總管旁保留至少 `320px` 的寬度：

- 在寬度小於物件總管寬度加上 `320px` 的編輯器中，物件總管會繪製得較窄以符合空間，最窄為 `200px`。
- 在寬度小於 `520px` 的編輯器中，物件總管會讓出位置。它不會被繪製，但仍保持開啟，因此工具列按鈕仍顯示為按下狀態，按下按鈕會將其關閉。一旦編輯器夠寬，它就會以其自身的寬度恢復。

計算的是編輯器本身的寬度，而不是瀏覽器視窗的寬度，即使[開啟與關閉](#opening-and-closing)中的快顯通知提到的是視窗。

在[由右至左的顯示語言](./language-and-theme.md#right-to-left-languages)中，物件總管仍位於畫布左側，因為畫布永遠不會鏡像翻轉。  
其內容由右至左閱讀：標題列、搜尋和各列都會鏡像翻轉，且各列從右側縮排。拖曳的邊緣仍在其右側，緊鄰畫布。資料類型、索引欄位和外鍵文字則維持由左至右的順序。

## 暫時隱藏的情況 {#when-it-stands-aside}

物件總管只會顯示在 ERD 索引標籤中。  
切換到其他索引標籤會將其隱藏，工具列按鈕也不再顯示為按下狀態。回到 ERD 索引標籤時，它會以離開時的狀態再次顯示，摺疊狀態和捲動位置都相同。

[差異檢視器](./table-related-functions.md#diff-viewer)、[時光旅行](./undo-redo.md#time-travel)或[自動版面配置](./table-related-functions.md#auto-layout)預覽開啟期間，任何操作都無法開啟或關閉物件總管：

- 已開啟的物件總管會被隱藏，並在它們關閉後再次顯示。
- 工具列按鈕會變暗，且不會有任何作用。
- `Toggle Explorer` 不會出現在快速搜尋中。
- 快速鍵會交由瀏覽器或主應用程式處理，請參閱[瀏覽器的尋找列](./find-and-replace.md#the-browsers-find-bar)。

差異檢視器也會以同類的樹狀結構列出其變更，請參閱[差異檢視器](./table-related-functions.md#diff-viewer)。

使用 `Alt + Z` (Windows/Linux) 或 `⌥ + Z` (Mac) 開啟[禪模式](./table-related-functions.md#canvas-toolbar)時，已開啟的物件總管會被隱藏但不會關閉，關閉禪模式則會讓物件總管恢復。  
在禪模式中，快速鍵和這兩個 `Toggle Explorer` 項目仍會開啟物件總管並定位到其搜尋，而禪模式維持開啟。此時物件總管會涵蓋編輯器的整個高度，因為頂端工具列已隱藏，且關閉禪模式後仍會保持顯示。再次開啟禪模式會再次將其隱藏。

每當面板在鍵盤焦點位於其中時消失，無論是被關閉、被隱藏或讓出位置，鍵盤焦點都會回到編輯器。

## 樹狀結構 {#the-tree}

標題列顯示 `Explorer`，並包含兩個按鈕：`Collapse All`，以及可關閉物件總管的 `x`。其下方是搜尋（請參閱[尋找與取代](./find-and-replace.md)），再下方則是樹狀結構。

最上層依序包含三個資料夾：`Tables`、`Table Groups` 和 `Memos`。每個資料表下方各有其自身的 `Columns`、`Indexes` 和 `Foreign Keys` 資料夾。  
沒有任何內容的資料夾不會顯示，因此空白的圖表完全不會顯示任何列。當 [View Option](./table-related-functions.md#table-view-options) → `Table Groups` 隱藏群組時，`Table Groups` 也會被省略；當 View Option → `Memos` 隱藏備忘錄時，`Memos` 也是如此。  
資料夾列會顯示資料夾圖示、資料夾名稱，並在最末端顯示直接位於其下的列數，因此 `Tables` 旁的計數就是圖表中的資料表數量。計數會依顯示語言的方式為千位數分組，且一律使用數字 0 到 9，例如英文為 `1,234`，德文為 `1.234`。

資料表依名稱排列，不區分大小寫，名稱相同的資料表則沿用文件中的順序。資料表群組以相同方式排列，每個群組下的資料表也是如此。資料表的欄位沿用資料表本身的順序，其索引、外鍵以及備忘錄則沿用文件中的順序。  
樹狀結構會隨圖表的變更而更新，無論變更來自畫布上的編輯、復原或重做、匯入，還是協作者或程式碼代理程式，因此重新命名資料表會使其所在的列移動位置。  
在每種[顯示方式](./logical-names.md#name-view)下，順序都依名稱排列，永遠不會依邏輯名稱排列。切換顯示方式會更新資料表列和欄位列所顯示的名稱，而不會移動其中任何一列；在 `Logical Names` 或 `Both Names` 中為資料表或欄位設定邏輯名稱時也是如此。不過，依新的邏輯名稱[產生](./dictionary.md#deriving-physical-names)的物理名稱與任何其他重新命名一樣，因此可能會移動資料表的列。

各種列顯示的內容：

- 資料表：資料表圖示及其名稱。
- 欄位：主鍵或外鍵欄位會顯示鑰匙圖示，其顏色與資料表本身的鍵儲存格標示主鍵、外鍵或兩者時的顏色相同，其他欄位則顯示清單圖示。接著是其名稱，以及以淡色顯示的資料類型，後面接著 `PK`、`FK` 或兩者，例如 `id` `BIGINT PK` 或 `user_id` `BIGINT FK`。無論顯示方式為何，它所顯示的類型一律是欄位的資料類型，永遠不會是其[定義域](./logical-names.md#the-domain-cell)。
- 索引：索引圖示及其名稱。接著以淡色顯示：唯一索引會顯示 `UNIQUE`，然後在括號中依索引順序列出其欄位，遞減排序的欄位後面會加上 `DESC`，例如 `orders_user_idx` `UNIQUE (user_id DESC, total)`，或只有 `(total)`。
- 外鍵：只列在子資料表（也就是包含外鍵欄位的資料表）下方，且只在父資料表位於圖表中時列出。其鑰匙圖示會採用連接線的顏色：[識別關聯](./relationship-editing.md#identifying-relationships)為主鍵兼外鍵的顏色，其他情況則為外鍵的顏色。它會顯示子資料表的鍵欄位（以逗號分隔），接著以淡色顯示 `→` 以及父資料表與其欄位，例如 `user_id` `→ users(id)`。
- 資料表群組：一個群組顏色的圓點（沒有顏色的群組為灰色）及其名稱。其資料表會依名稱列在其下方，每一列都會前往其資料表。沒有資料表的群組沒有可展開的內容。
- 備忘錄：便利貼圖示及備忘錄的第一行。

資料表列、列在群組下方的資料表和欄位列都會依循「名稱顯示」，請參閱[畫布以外的地方](./logical-names.md#beyond-the-canvas)。例如在 `Both Names` 中，欄位列會顯示 `Total Amount` `total` `NUMERIC`：先是邏輯名稱，接著是名稱和資料類型，兩者都以淡色顯示。  
在每種顯示方式下，索引列和外鍵列都會以名稱顯示其欄位，外鍵列也會以名稱顯示其父資料表。  
「尋找」輸入框中有文字時，只在其顯示方式所省略的名稱中被找到的列，也會以淡色顯示該名稱，請參閱[搜尋結果](./find-and-replace.md#the-results)。

空白的名稱，或第一行為空白的備忘錄，會以斜體顯示 `unnamed`。在 `Logical Names` 和 `Both Names` 中，只有在邏輯名稱也是空白時，資料表或欄位才會顯示 `unnamed`。  
面板較窄時，淡色文字會先於該列開頭的名稱以 `…` 截斷。將指標停留在名稱或其淡色文字上即可查看完整內容。

一開始只有 `Tables` 是展開的。按一下資料夾列，或在其上按 `Enter` 或 `Space`，即可將其摺疊或展開。  
列開頭的箭頭會摺疊或展開該列，而不會前往任何位置。每個資料表列都有箭頭，即使是下方沒有任何內容的資料表也一樣。`→` 和 `←` 也可以摺疊和展開，請參閱[物件總管中的按鍵](#keys-in-the-explorer)。  
`Collapse All` 每按一次會摺疊一層：也就是目前顯示的已展開列中最深的一層，因此連續按下會由下而上摺疊。到達最上層的那一次按下會摺疊所有列（包括位於已摺疊列之下的列），只留下最上層的資料夾。  
編輯、復原和重做，以及來自協作者或程式碼代理程式的變更，都會讓摺疊狀態維持原樣。

## 前往某一列 {#going-to-a-row}

按一下某列，或在鍵盤焦點位於該列時按 `Enter` 或 `Space`，即可前往其在 ERD 畫布上所代表的項目。資料夾列只會摺疊或展開，方向鍵也只會在樹狀結構中移動。

- 資料表列，或列在群組下方的資料表，會只選取該資料表並將其移到最前面。除非焦點儲存格已在該資料表中，否則它會移到資料表表頭的第一個儲存格：名稱，在 `Logical Names` 和 `Both Names` 中則為邏輯名稱。
- 欄位列會只選取其資料表，並將焦點儲存格放在該欄位的名稱上，在 `Logical Names` 中則放在其位置所繪製的邏輯名稱上。
- 索引列會像資料表列一樣選取其資料表。索引本身不會被單獨標示；索引需在「[資料表屬性](./table-related-functions.md#indexes)」中編輯。
- 外鍵列會將關聯的兩個資料表一起捲動到可見範圍內，若兩者相距太遠而無法同時顯示，則為子資料表。它會只選取子資料表及其外鍵欄位，焦點儲存格位於其中第一個欄位上，並讓關聯的連接線亮起，請參閱[解讀連接線](./relationship-editing.md#reading-a-connector)。
- 資料表群組列會以標題列為準將群組的方框捲動到可見範圍內，只選取該群組，並將其連同其資料表移到最前面。
- 備忘錄列會只選取該備忘錄，並將其移到最前面。

檢視會依所有前往操作共用的規則移動：縮放比例絕不會變更，且只有在前往的目標尚未清楚顯示時，畫布才會捲動，請參閱[跳至目標時的落點](./table-related-functions.md#where-a-jump-lands)。  
若「資料表屬性」為開啟狀態，前往某一列會先將其關閉，且絕不會開始或完成正在繪製的關聯。  
「尋找」輸入框中有文字時，名稱或邏輯名稱含有相符項目的列，或顯示註解或備忘錄摘錄的列，會改為前往其第一個相符項目，請參閱[前往相符項目](./find-and-replace.md#going-to-a-match)。

按一下之後，鍵盤焦點會留在樹狀結構中，因此在按 `Escape` 或按一下畫布之前，`Delete`、`Backspace` 和其他編輯按鍵都不會作用於新的選取範圍，請參閱[物件總管中的按鍵](#keys-in-the-explorer)。

## 物件總管中的按鍵 {#keys-in-the-explorer}

樹狀結構在 `Tab` 鍵順序中只佔一個停駐點，沒有任何列時會被略過。  
以 `Tab` 鍵進入樹狀結構時，會落在鍵盤焦點上次所在的列；若沒有，則落在目前相符項目所在的列，或第一個完全位於可見範圍內的列，並將該列捲動到可見範圍內。鍵盤焦點所在的列會以與指標下方的列相同的方式繪製。

在樹狀結構中：

- `↑` 和 `↓` 會移動一列，到達第一列和最後一列時會停止，而不會循環。`Home` 和 `End` 會移到第一列和最後一列。
- `→` 會展開已摺疊的列，或移入已展開列的第一個子項目。`←` 會摺疊已展開的列，或移出至其父項目。在由右至左的顯示語言中，兩者會互換。
- `Enter` 和 `Space` 的作用與按一下相同：前往該列，或摺疊或展開資料夾，請參閱[前往某一列](#going-to-a-row)。
- 輸入字母不會跳至某一列。

在物件總管中的任何位置（樹狀結構中、「尋找」或「取代」輸入框中，或其某個按鈕上）按 `Escape`，都會將鍵盤焦點交還給畫布。物件總管會保持開啟，選取範圍也維持原樣。  
用來結束輸入法組字的 `Escape` 只會結束組字。無論是在物件總管中還是在畫布上按下，`Escape` 都絕不會關閉物件總管。

鍵盤焦點位於物件總管中時，少數編輯器快速鍵仍然有效，請參閱[快速鍵](./settings.md#shortcuts)：

- `Ctrl + F` (Windows/Linux) 或 `⌘ + F` (Mac) 的作用與在畫布上相同：關閉物件總管；若「資料表屬性」在其旁邊開啟，則會關閉「資料表屬性」並將插入點放入「尋找」輸入框，請參閱[開啟與關閉](#opening-and-closing)。
- `Ctrl + K` (Windows/Linux) 或 `⌘ + K` (Mac) 會切換快速搜尋。
- `Undo` 和 `Redo` 會復原和重做圖表，而不是輸入框中的文字。
- `Zoom In`、`Zoom Out` 和 `Zoom Reset` 會縮放畫布。

其他所有編輯器快速鍵都會留在物件總管中，方向鍵、`Tab`、`Enter`、`Space`、`Home`、`End`，以及輸入法組字期間按下的任何按鍵也是如此。  
這些按鍵都不會傳到畫布：`Delete` 和 `Backspace` 絕不會刪除選取範圍，`Alt + N` (Windows/Linux) 或 `⌥ + N` (Mac) 不會新增資料表，先按 `T` 再按 `G` 也不會建立任何群組。在輸入框中，它們會作為一般的文字按鍵：`Ctrl + A` (Windows/Linux) 或 `⌘ + A` (Mac) 會選取輸入框中的文字，`Delete` 和 `Backspace` 會清除文字，`Space` 則會輸入空格。`Tab` 會在物件總管的按鈕、輸入框和樹狀結構之間移動。  
關於「尋找」與「取代」輸入框本身的按鍵，請參閱[搜尋輸入框中的按鍵](./find-and-replace.md#keys-in-the-search-fields)。  
編輯器未繫結的按鍵，例如主應用程式本身的儲存或命令選擇區，會照常傳到主應用程式。

## 物件總管旁的對話方塊 {#dialogs-beside-it}

「[資料表屬性](./table-related-functions.md#table-properties)」、[佈景主題建立器](./language-and-theme.md#theme)、[`Display Language`](./language-and-theme.md#picking-a-language) 選擇器、[`Export image`](./file-import-export.md#image) 對話方塊和「[對應欄位](./relationship-editing.md#map-columns)」開啟時，都會讓物件總管保持開啟。

- 「資料表屬性」會在物件總管旁的畫布中央開啟，且只會讓畫布變暗。物件總管仍可使用：選擇某一列會關閉「資料表屬性」，然後前往該列。
- `Export image` 和「對應欄位」會讓整個編輯器變暗，包括工具列和物件總管。物件總管會在變暗的區域下方保持開啟，在該處按一下會關閉對話方塊，就像在變暗區域的任何位置按一下一樣；此時「對應欄位」會直接關閉，而不對應任何內容。
- 在由左至右的顯示語言中，佈景主題建立器和 `Display Language` 選擇器會緊鄰物件總管開啟，而不會蓋在其上方，若在它們顯示期間物件總管開啟或關閉，它們也會隨之移動。在由右至左的語言中，它們會維持在右側的位置。在物件總管中按下會關閉它們，就像在它們以外的任何位置按下一樣，但在工具列上按下除外。

以快速鍵或 `Toggle Explorer` 項目開啟搜尋時，這五個都會關閉，其中「對應欄位」會在不對應任何內容的情況下關閉。  
[快速搜尋](./quick-search.md)也會讓物件總管保持開啟，此時 `Escape` 只會關閉命令選擇區。

## 唯讀編輯器 {#read-only-editors}

在 [`readonly`](../../api/erd-editor-element.md#readonly) 編輯器中，物件總管的運作方式與在其他編輯器中相同：工具提示相同的工具列按鈕、快速鍵、快速搜尋中的 `Toggle Explorer` 項目、樹狀結構、摺疊和 `Collapse All`。其標題在該處也顯示為 `Explorer`。畫布右鍵選單在該處沒有 `Toggle Explorer`，因為它只保留可供閱讀的項目，請參閱[唯讀編輯器](./table-related-functions.md#read-only-editors)。

前往某一列的運作方式與[前往某一列](#going-to-a-row)相同：檢視依相同的規則移動，而該列的資料表、資料表群組或備忘錄會被選取，並在畫布上以外框標示，焦點儲存格則在該列所指定的位置。  
這是唯讀編輯器選取任何東西的唯一方式。在畫布上按下不會選取任何東西，而單擊（不移動）會清除某一列所留下的選取範圍。被它選取的資料表可用 `Alt + Space` (Windows/Linux) 或 `⌥ + Space` (Mac) 在[資料表屬性](./table-related-functions.md#table-properties)中開啟（唯讀），而 `Ctrl + C` (Windows/Linux) 或 `⌘ + C` (Mac) 會像在任何編輯器中一樣複製它所選取的內容。  
其搜尋只能尋找，請參閱尋找與取代中的[唯讀編輯器](./find-and-replace.md#read-only-editors)。
