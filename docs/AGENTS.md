### Common Patterns

- All 31 pages have the same front matter: `sidebar_position` and `description`, nothing else.
  With no `title`, `id` or `slug`, the file name is the URL and the H1 is the sidebar label. All 24
  translations copy `sidebar_position`, so reordering pages means editing all 25 copies.
- No page uses an admonition (`:::`) or a blockquote. A caveat is a plain sentence.
- A cross-reference ends a sentence as `— see [Heading](./page.md#anchor)`: 375 times in `guide/`,
  103 in `api/`, 63 in `mcp/`.
- Hard breaks are a per-page choice. `api/installation.md`, `guide/guides/settings.md` and the four
  `mcp/` pages have none. Match the page: `grep -c '[^ ]  $' <page>`.
- UI labels, values and setting names go in backticks, spelled as the editor's English strings in
  `../erd-editor/packages/erd-editor/src/i18n/messages/en/` (`'common.newTableGroup': 'New Table Group'`).
  Check one there before writing it: `grep -rn "'New Table Group'" <that dir>`.
- Host menu paths are plain text in each host's separators: Settings → ERD Editor (Obsidian),
  Settings | Tools | ERD Editor (JetBrains). An editor menu path has the menu bare and the item in
  backticks: View Option → `Domain`.
- A shortcut pair reads `` `Ctrl + F` (Windows/Linux) or `⌘ + F` (Mac) ``; a sequence reads
  `` `T` then `G` ``.
- Every code fence names its language: `js`, `ts`, `html`, `json`, `sh`, `css`, `toml`, and one `diff`.
